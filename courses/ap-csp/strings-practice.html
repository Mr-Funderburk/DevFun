Practice Set: String Manipulation

Test your knowledge of string concatenation, indexing rules, string methods, slicing parameters, escape characters, and f-strings. Write Python code segments to solve each of the following scenarios.

Easy Problems

Problem 1: User Input Standardization

When users enter text, they often accidentally include extra spaces or unpredictable capitalization. Given a variable raw_input = " vOLleYbaLL ", write a code segment that cleans the string by removing extra whitespace and converting it entirely to lowercase. Print the final result.

Problem 2: Simple String Length Check

Write a code segment that checks the character length of a string variable named username. If the length is less than 6 characters, print "Username too short". Otherwise, print "Valid username".

Problem 3: Receipt Formatting with Escape Sequences

Write a single print() statement using escape characters (\n and \t) to display the following output exactly as shown below:

output.txt 
Receipt:
	Coffee:	$3.50
	Muffin:	$2.75

Problem 4: Explicit Concatenation

Given the variables item = "Notebook", qty = 4, and price = 2.50, write a single print() statement using string concatenation (+) and explicit type casting (str()) to output: "Order: 4 Notebook(s) at $2.50 each."

Medium Problems

Problem 5: Golden Rule of Indexing

Remember: "The index is always the count minus one!" Given a variable word = "ALPHABET":

  • Write a statement to extract and print the 1st character using its index.
  • Write a statement to extract and print the 5th character using its index.
  • Write a statement to extract and print the last character without hardcoding a number (use len()).

Problem 6: Character Replacement Pipeline

Given the string variable code_str = "100-200-300-400", write a code segment that replaces all hyphens (-) with spaces, and then prints the length of the newly formatted string.

Problem 7: Basic Slicing Extraction

Given the variable filename = "document_v2_final.pdf", write slicing statements to perform the following:

  • Extract and print the first 8 characters ("document").
  • Extract and print the last 3 characters ("pdf") using negative indexes.

Problem 8: Modern f-String Conversion

Convert the following explicit concatenation snippet into a single clean line of code using an f-string:

main.py 
# Rewrite this line into an f-string
print("Student " + name.upper() + " has " + str(absences) + " absence(s).")

Problem 9: Every Other Character (Step Parameter)

Given the string alphabet = "abcdefghijklmnopqrstuvwxyz", write a single slicing expression using the step parameter that extracts and prints every 2nd letter starting from 'a' (i.e., "aceg...").

Hard Problems

Problem 10: String Reversal & Palindrome Detector

A word is a palindrome if it reads the same forward and backward (e.g., "racecar"). Given a variable test_word = "radar", write a code segment using Python's step slice shortcut (::-1) and an if/else statement that prints "Palindrome!" if the word is identical backward, or "Not a palindrome" if it isn't.

Problem 11: Credit Card Masking

Cybersecurity applications often mask sensitive numbers before displaying them on screen. Given a 16-digit credit card number string like card_number = "4532890123456789", write a code segment that creates a masked string where the first 12 digits are replaced with asterisks (*) and only the last 4 digits remain visible. Output should look like: "************6789".

Problem 12: Pig Latin Converter (Single Word)

In simplified Pig Latin, if a word begins with a consonant, move the first letter to the end of the word and append "ay" (for example, "python" becomes "ythonpay").

Given a variable word = "computer", write a code segment using string indexing and slicing to transform word into its Pig Latin equivalent and print the result.

Problem 13: Initial Generator

Given a string variable containing a person's full name in the format full_name = "john quincy adams", write a code segment that:

  1. Cleans up any surrounding spaces and converts the full string to uppercase.
  2. Slices out the first letter of each of the three names (assuming fixed word positions: First name starts at index 0, Middle name starts at index 5, Last name starts at index 12).
  3. Prints the initials joined by periods (e.g., "J.Q.A.").
