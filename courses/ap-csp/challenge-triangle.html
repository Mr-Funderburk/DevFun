Weekly Challenge: Telemetry Engine - Spatial Mesh Validator

Apply string parsing, type casting, and multi-way branch conditionals to build a drone spatial geometry analyzer.

Background Scenario

You are developing a spatial mapping module for autonomous drones. Before deploying a three-node communications relay, the navigation engine must verify that the relative distances between three relay positions satisfy the Triangle Inequality Theorem:

(a + b > c)  &&  (a + c > b)  &&  (b + c > a)

If the distances fail this test, the positions cannot form a valid closed boundary. If the boundary is valid, the system classifies the geometry of the relay zone to optimize signal routing.

Classification Rules

Your program must evaluate three side lengths (a, b, c) in sequence using the following logic hierarchy:

  • Invalid Boundary: The distances fail the Triangle Inequality Theorem → Return "Not a Triangle"
  • Equilateral: All three side lengths are strictly equal (a = b = c) → Return "Equilateral"
  • Isosceles: Exactly two side lengths are equal (a = b or a = c or b = c) → Return "Isosceles"
  • Scalene: All three side lengths are completely different (a ≠ b ≠ c) → Return "Scalene"

Required Function Specification

You must write a function named triangle(sides) that adheres strictly to the following parameters:

  • Function Name: triangle
  • Parameter: sides - The parameter sides will be a single string containing three comma-separated integer distances (e.g., "15,15,20").
  • Behavior: Compute the type of triangle.
  • Return Value: Your function must return one of the four exact string values: "Not a Triangle", "Equilateral", "Isosceles", or "Scalene".

CRITICAL: Exact Names Required

Automated grading scripts will evaluate your submission. Your file name, function name (change), parameter name (amount), and global variable name (NAME) must match the instructions EXACTLY. Misspelling any of these elements will cause autograding scripts to fail, resulting in a lower score!

Sample Test Cases

Your solution must pass all boundary conditions listed below:

Input String (sides) Expected Return String Reasoning
"15,15,22" "Isosceles" Valid geometry; two side lengths are equal (15 == 15).
"10,10,10" "Equilateral" Valid geometry; all three side lengths are equal.
"12,16,20" "Scalene" Valid geometry; all three side lengths are distinct.
"5,8,20" "Not a Triangle" Invalid geometry (5 + 8 < 20). Cannot form a closed shape.
