Everything Flexbox!

Mastering One-Dimensional Layouts

Before Flexbox (Flexible Box Layout), aligning elements side-by-side or centering things vertically required tricky hacks using float, display: inline-block, or complex calculated margins. Flexbox revolutionized CSS layout by providing a predictable, powerful way to distribute space and align items along a single axis.

The Golden Rule of Flexbox

Flexbox works on a Parent-Child relationship. You apply display: flex to a Flex Container (the parent element), and its direct child elements automatically become Flex Items.

1. The Two Axes & flex-direction

Flexbox operates on two distinct imaginary lines: the Main Axis and the Cross Axis.

  • Main Axis: The primary direction flex items flow (left-to-right by default). Controlled by justify-content.
  • Cross Axis: The perpendicular line running across the main axis (top-to-bottom by default). Controlled by align-items.

You can change the orientation of these axes using the flex-direction property on the flex container:

Flex Direction Values
Property Value Main Axis Direction Cross Axis Direction
row (Default) Horizontal (Left → Right) Vertical (Top ↓ Bottom)
row-reverse Horizontal (Right → Left) Vertical (Top ↓ Bottom)
column Vertical (Top ↓ Bottom) Horizontal (Left → Right)
column-reverse Vertical (Bottom ↑ Top) Horizontal (Left → Right)

2. Main Axis Alignment: justify-content

The justify-content property determines how extra space is distributed along the Main Axis.

Justify Content Options
Value Visual Behavior
flex-start (Default) Packs items tight against the start of the main axis.
flex-end Packs items tight against the end of the main axis.
center Centers items together in the middle of the container.
space-between Pushes first and last items to the edges, evenly spacing items in between.
space-around Gives every item equal space around both its left and right sides.
space-evenly Distributes empty space identically between items and container edges.

3. Cross Axis Alignment: align-items & align-self

To control alignment perpendicular to your main axis (e.g., vertical alignment in a standard row), use align-items on the container.

  • stretch (Default) — Stretches items to fill the height/width of the container cross-axis.
  • center — Centers items vertically along the cross-axis.
  • flex-start — Aligns items to the top (or start) of the cross-axis.
  • flex-end — Aligns items to the bottom (or end) of the cross-axis.
  • baseline — Aligns items so that their text baseline lines up cleanly.

Overriding Individual Items with align-self

Want a single flex item to break away from its siblings? Apply align-self directly to a child item! For example, .special-item { align-self: flex-end; } will move only that item to the bottom, ignoring the parent's align-items setting.

4. Multi-Line Flex: flex-wrap & gap

By default, flex containers force all children onto a single row (flex-wrap: nowrap), squishing items if space runs out. To allow flex items to wrap onto new lines when the container shrinks, use flex-wrap: wrap.

Combine wrapping with gap to manage clean gutters between items without margins:

wrapping-grid.css
CSS 
.card-container {
    display: flex;
    flex-wrap: wrap; /* Allows cards to drop to a new line */
    gap: 24px;       /* Adds 24px space between both rows and columns */
    justify-content: center;
}

5. Flex Item Sizing: Grow, Shrink & Basis

Flex items are dynamic! You can control how child items expand or shrink to fill empty space using three key properties on the child selectors:

  1. flex-grow: Determines how much an item grows relative to its siblings when space is available (e.g. 1 means grow equally, 2 means grow twice as fast).
  2. flex-shrink: Determines how much an item shrinks if there isn't enough space (default is 1). Set to 0 to prevent an item from shrinking!
  3. flex-basis: The initial base size of the item before extra space is distributed (e.g. 250px or 20%).

The flex Shorthand: Combine these into a single property: flex: <grow> <shrink> <basis>.

flex-shorthand.css
CSS 
/* Equal width flexible columns */
.col {
    flex: 1; /* Equivalent to: flex: 1 1 0% */
}

/* Fixed sidebar, fluid main content */
.sidebar {
    flex: 0 0 280px; /* Don't grow, don't shrink, stay 280px wide */
}

.main-content {
    flex: 1; /* Take up all remaining space */
}

Putting It Together

In your web-1/learning/ folder, create a file named flexbox-demo.html and link it to flexbox.css.

flexbox-demo.html
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox Feature Layout</title>
    <link rel="stylesheet" href="flexbox.css">
</head>
<body>
    <div class="page-wrapper">
        <header class="hero-section">
            <h1>Responsive Flexbox Layouts</h1>
            <p>Mastering alignment, spacing, and sizing.</p>
        </header>

        <!-- App Layout with Sidebar + Content -->
        <div class="app-container">
            <aside class="sidebar">
                <h3>Sidebar Navigation</h3>
                <ul class="sidebar-links">
                    <li><a href="#">Dashboard</a></li>
                    <li><a href="#">Settings</a></li>
                    <li><a href="#">Profile</a></li>
                </ul>
            </aside>

            <main class="main-content">
                <h2>Feature Grid</h2>
                
                <!-- Flex Wrapping Card Container -->
                <div class="card-grid">
                    <article class="card">
                        <h3>Feature One</h3>
                        <p>Flex item with flex-grow enabled to distribute space evenly.</p>
                    </article>

                    <article class="card featured-card">
                        <span class="badge">Popular</span>
                        <h3>Feature Two</h3>
                        <p>Overridden using custom align-self alignment!</p>
                    </article>

                    <article class="card">
                        <h3>Feature Three</h3>
                        <p>Wraps cleanly onto the next line when screen size shrinks.</p>
                    </article>
                </div>
            </main>
        </div>
    </div>
</body>
</html>

Now write the complete Flexbox stylesheet inside flexbox.css:

flexbox.css
CSS 
/* Universal Reset */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    background-color: #0b1020;
    color: #e2e8f0;
    font-family: sans-serif;
    padding: 24px;
}

/* 1. Perfect Centering with Flexbox */
.hero-section {
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    min-height: 160px;
    background-color: #1e293b;
    border-radius: 8px;
    margin-bottom: 24px;
    text-align: center;
}

/* 2. Main App Container (Sidebar + Main Content Row) */
.app-container {
    display: flex;
    gap: 24px;
}

/* Fixed Sidebar */
.sidebar {
    flex: 0 0 240px; /* Don't grow, don't shrink, fix width to 240px */
    background-color: #151d32;
    padding: 20px;
    border-radius: 8px;
}

.sidebar-links {
    list-style: none;
    margin-top: 16px;
    display: flex;
    flex-direction: column;
    gap: 10px;
}

.sidebar-links a {
    color: #38bdf8;
    text-decoration: none;
}

/* Fluid Main Content Area */
.main-content {
    flex: 1; /* Takes up all remaining horizontal space */
    background-color: #151d32;
    padding: 20px;
    border-radius: 8px;
}

.main-content h2 {
    margin-bottom: 16px;
}

/* 3. Responsive Wrapping Card Grid */
.card-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
    align-items: stretch; /* Cards in a row share equal height */
}

.card {
    flex: 1 1 200px; /* Grow equally, shrink if needed, target 200px base */
    background-color: #1e293b;
    border: 2px solid #334155;
    padding: 20px;
    border-radius: 6px;
    display: flex;
    flex-direction: column;
    justify-content: space-between;
}

/* Badge positioned inside flex card */
.badge {
    align-self: flex-start; /* Keeps badge contained to its text width */
    background-color: #38bdf8;
    color: #0f172a;
    font-weight: bold;
    font-size: 12px;
    padding: 4px 8px;
    border-radius: 4px;
    margin-bottom: 12px;
}

.featured-card {
    border-color: #38bdf8;
}

Practice Exercise & Challenges

Put your Flexbox superpowers to the test with these practical exercises:

  1. The Holy Grail Centering Trick: Create a full-screen hero box (min-height: 100vh) and use display: flex, justify-content: center, and align-items: center to perfectly center a login card in the dead middle of the screen both horizontally and vertically.
  2. Build a 3-Column Pricing Table: Create three pricing cards side-by-side using Flexbox. Make the middle "Pro" card taller and highlight it using align-self: center or transform: scale(1.05)!
  3. Flex Direction Toggle Challenge: Turn the .app-container in your example into a column on small screens by adding a media query rule, or practice changing flex-direction: row to flex-direction: column to see how justify-content and align-items swap roles!
  4. Equal-Height Card Equalizer: Create three cards with different amounts of text (one short sentence, one long paragraph). Notice how Flexbox's default align-items: stretch keeps all three cards at identical heights automatically!
