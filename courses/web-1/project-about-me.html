Major Project: 6-Page Personal Website

Project Objective

It is time to pull together everything you have learned in Web Development 1 into a complete, multi-page website! Your task is to build a cohesive, 6-page personal website that demonstrates semantic HTML5 layout structure, CSS design continuity, Flexbox grid positioning, and custom styling techniques.

The "B" vs. "A" Grade Benchmark

The code showcased in class provides a solid baseline for a "B" grade. To earn an "A" grade, you must expand beyond basic layouts by creating customized visual styles, richer content sections, and successfully researching and implementing a brand-new CSS property not covered in the starter template.

Grading Standards & Requirements

Project Evaluation Criteria
Category Baseline Requirements ("B" Grade Level) Excellence & Customization ("A" Grade Level)
Page Count & Structure 1 Homepage (index.html) plus 5 distinct topic sub-pages (e.g., Family, Games, Programming, Motorcycles, SCUBA, or topics of your choice). Distinct layout variations per page, interactive image galleries, rich lists, or custom tabular data layouts.
Design Continuity All 6 pages share matching navigation bars, header banners, font stacks, and a consistent primary color palette. Polished custom typography, unique color accents, refined margin/padding rhythm, and subtle visual depth.
Navigation & Links Functional working navigation across all headers. Correct relative linking between internal pages, plus at least one external absolute link. External links open cleanly in a new tab (target="_blank"), with active page state styling on the navigation bar.
Content & Assets Completes all content areas with descriptive text and functional non-broken images in an /images folder. Original written copy with zero raw placeholder text, custom image captions, and well-structured sub-headings.
CSS Research Challenge Uses default baseline CSS starter styles without adding new properties. Researches, implements, and comments on at least one new CSS property not present in the starter code. Prepared for a 30-sec explanation.

Understanding Relative vs. Absolute Links

Your project must demonstrate two distinct types of hyperlinks:

  • Relative Internal Links: Used to navigate between pages inside your project folder without specifying a domain name.
  • Absolute External Links: Used to point to external websites on the internet. Must include the full URL protocol and open in a new browser window/tab.

Leveling Up to an "A": The New CSS Property Challenge

To reach an "A" grade, you must research and implement at least one property we have not discussed in class. You must place an explanatory CSS comment directly above your implementation and be ready to explain it in 30 seconds during class evaluation.

Here are several ideas for new properties you can research and include:

  • box-shadow
  • transition
  • transform
  • filter
  • gradients

Final Submission Checklist

Before compressing your project for turn-in, double check every item on this checklist:

  1. Root Folder Organization: Contains index.html, 5 distinct sub-page HTML files, a /css subfolder with your stylesheet, and an /images subfolder with all image files.
  2. Navigation Test: Every nav link works seamlessly from every page with no broken relative pathways or 404 errors.
  3. Image Check: All images load properly, utilize descriptive alt text, and maintain proportions without squishing or stretching.
  4. Absolute External Link: Contains at least one external hyperlink using target="_blank" to open in a new browser tab.
  5. CSS Comment Requirement: Contains a clear comment directly above your newly researched CSS property explaining what it does.
  6. ZIP Archive: Compress your entire root directory into a single .zip file and upload it to the submission portal.
