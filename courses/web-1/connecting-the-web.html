Connecting the Web

Supercharging Tags with Attributes

Up until now, every HTML element we've written works automatically. An <h1> makes big bold text, and a <p> creates a text paragraph. But what if we want to tell a tag where to go or which image file to display?

That's where attributes come in. Attributes are key-value pairs written inside the opening tag that provide extra instructions or settings to the browser. They always follow this syntax: name="value".

Anatomy of an Attribute

<element attribute="value">Content</element>

Notice that attributes live inside the opening angle bracket (<...>), before the closing bracket.

Setting Up Your Images Folder

Before adding images to our pages, we must organize our files according to our web rules. Keeping project files organized keeps path references clean and prevents broken links.

  1. Open your main web-1 folder.
  2. Navigate into the learning folder.
  3. Create a new folder inside learning called images (all lowercase, no spaces!).

Your folder path should now look like this: web-1/learning/images/.

Relative vs. Absolute Linking

When linking to another webpage or loading an image, we need to tell the browser where to find that file using a file path. There are two ways to write paths:

1. Absolute Paths

An absolute path is a full web address (URL) pointing to a resource somewhere on the internet. It includes the complete address protocol (like https://).

Example: https://www.wikipedia.org/portal/wikipedia.org/assets/img/Wikipedia-logo-v2.png

Use case: Linking off your website to an external site like Google, YouTube, or Wikipedia.

2. Relative Paths (Our Primary Method)

A relative path points to a file relative to the location of the current file you are working on inside your project folder.

Example: images/logo.png

Use case: Linking to other pages or displaying images within your own website.

Why Preference Relative Paths?

Relative paths ensure your website works everywhere—whether running on your local computer, stored on a flash drive, or uploaded to a live web server. If you use absolute paths to your local hard drive, nobody else on the web will be able to see your images or open your pages!

1. The Anchor Tag (<a>)

The anchor tag creates hyperlinks to other web pages or files. On its own, <a>Click Here</a> won't do anything because it doesn't know where to link! It requires the href (Hypertext REFerence) attribute.

Absolute Link (External Website):

<a href="https://www.wikipedia.org" target="_blank">Visit Wikipedia</a>

Note: Adding target="_blank" tells the browser to open the link in a brand-new tab.

Relative Link (Internal Page):

<a href="common-elements.html">Common HTML Elements</a>

2. The Image Tag (<img>)

The image tag embeds pictures directly into your web page. The <img> tag is a void element—it does not have or need a closing tag.

It requires two critical attributes to work correctly:

  • src (Source): The file path pointing to the image location.
  • alt (Alternative Text): A textual description of the image for screen readers (accessibility) or to display if the image fails to load.

Relative Image (Local File):

<img src="images/banner.jpg" alt="A scenic mountain view at sunset">

Absolute Image (Online Web URL):

<img src="https://picsum.photos/400/200" alt="Random decorative photo from the web">

Putting It Together

In your web-1/learning/ folder, create a new file named links-and-images.html. Download or save any small image file into your new images folder (e.g., name it avatar.png or sample.jpg). Important: Make sure you are not just downloading the image and leaving it in your downloads! Get in the habit of giving your images meaningful names (using 'mountain-pass.jpg' instead of leaving 'user3241-u22244.jpg' or whatever nonsense name it has by default). Make sure you bring it into the correct folder!

Add the following code to your file and test it out in your web browser:

links-and-images.html
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Attributes: Links &amp; Images</title>
</head>
<body>
    <h1>Working with Attributes</h1>

    <h2>Navigation (Relative Links)</h2>
    <p>
        <a href="boilerplate.html">Lesson 1: Boilerplate</a> | 
        <a href="common-elements.html">Lesson 2: Common Elements</a>
    </p>

    <hr>

    <h2>External Links (Absolute Links)</h2>
    <p>Check out <a href="https://developer.mozilla.org" target="_blank">MDN Web Docs</a> for HTML reference.</p>

    <h2>Local Image (Relative Path)</h2>
    <p>Here is an image stored inside our local <code>learning/images/</code> folder:</p>
    <img src="images/avatar.png" alt="Student profile avatar icon">
    <!-- Change the src above to whatever image you downloaded! -->

    <h2>Online Image (Absolute Path)</h2>
    <p>Here is an image hosted externally on the web:</p>
    <img src="https://picsum.photos/300/150" alt="Placeholder image from online source">
</body>
</html>

Practice Exercise

Try applying what you've learned to build an interactive mini-portfolio page:

  1. Save a picture of your favorite animal or hobby into your web-1/learning/images/ folder.
  2. Add that image to your links-and-images.html page using a relative path and don't forget a descriptive alt attribute.
  3. Turn an image into a clickable button! Hint: Wrap an <img> tag inside an <a>...</a> link tag:
    <a href="https://google.com"><img src="images/avatar.png" alt="Google link"></a>
  4. Add relative back-links at the bottom of your common-elements.html and boilerplate.html pages so you can navigate across all your lessons seamlessly!
