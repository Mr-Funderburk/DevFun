Weekly Challenge: Vowel Counter

Introduction

The English alphabet contains five vowels—A, E, I, O, and U. The remaining 21 letters are called consonants. Vowels act as the glue of our language; without them, most words would be unpronounceable! Because of this, vowels make up some of the most frequently used letters in written text.

For your first weekly challenge, you will write a Python program that analyzes a string of text and calculates the total count of vowels present inside it.

Program Requirements

1. File Naming Convention

Create a new Python file named vowel_counter_lastname.py, replacing lastname with your actual last name in all lowercase letters.

  • Example: vowel_counter_funderburk.py
  • Note: If you have multiple last names, use the first last name listed in Cougar Campus.

2. Constant Definition

At the top of your script (after any necessary import statements), define a constant named NAME containing your first and last name as a string:

vowel_counter_lastname.py 
NAME = "Your First and Last Name"

3. Required Function Specification

You must write a function named vowel_counter(text) that adheres strictly to the following parameters:

  • Function Name: vowel_counter
  • Parameter: text (A string containing words without punctuation).
  • Behavior: The input string may contain both uppercase and lowercase letters. Your function must evaluate all vowels (A, E, I, O, U) regardless of letter case.
  • Return Value: Returns an int representing the total count of vowels found.

CRITICAL: Exact Names Required

Automated grading scripts will evaluate your submission. Your file name, function name (vowel_counter), parameter name (text), and global variable name (NAME) must match the instructions EXACTLY. Misspelling any of these elements will cause autograding scripts to fail, resulting in a lower score!
