Weekly Challenge: Orbital Guidance — Descent Corridor Validator

Parse delimited telemetry data, compute 2D vector slopes, and evaluate double-threshold tolerance ranges for atmospheric entry.

Introduction

You are serving as Flight Dynamics Lead for a deep-space research mission to Mars. Your planetary lander is approaching the upper atmosphere of Mars and must execute a precise entry corridor maneuver to land safely inside Jezero Crater. If the descent vector is too steep, friction will burn up the spacecraft; if it is too shallow, the probe will skip off the atmosphere back into deep space.

Before firing the atmospheric entry thrusters, your automated guidance engine must parse real-time telemetry, compute the slope of approach to both the start and end of the atmospheric landing gate, and confirm that both trajectory vectors fall strictly within target tolerances.

Mathematical Specifications

To determine if the trajectory is safe, calculate the slope (m) between the spacecraft position (xp, yp) and a target gate position (xt, yt) using the coordinate slope formula:

m = (yt - yp) / (xt - xp)

Both trajectory slopes (from the probe to the gate start position, and from the probe to the gate end position) must satisfy the safe corridor tolerance condition:

  • Target Tolerance Range: Slope m must be between -1.50 and -0.60 (inclusive).
  • Mathematical Condition: -1.50 ≤ m ≤ -0.60

Program Requirements

Strict Naming & Coding Requirements:

  • File Naming Rule: Name your Python file check_descent_lastname.py where lastname is replaced by your official last name (e.g., check_decent_funderburk.py).
  • Student Identifier Constant: Define a global variable named NAME near the top of the file containing your full name as a string:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named check_descent(probe_data) that accepts one parameter: probe_data.
  • Input Format: probe_data will be a single string containing four pipe-delimited (|) segments:
    "ProbeName|X_probe,Y_probe|X_start,Y_start|X_end,Y_end"
  • Return Outputs: Your function must return one of the two exact formatted string values:
    • "<ProbeName>, Entry Corridor Approved!" (if both slopes are within -1.50 to -0.60 inclusive)
    • "<ProbeName>, Abort Trajectory!" (if either or both slopes fall outside tolerance)

Sample Test Cases

Input Telemetry String (probe_data) Expected Return String Mathematical Reasoning
"AresOne|20,160|120,40|170,20" "AresOne, Entry Corridor Approved!" mstart = (40 − 160) / (120 − 20) = −1.20
mend = (20 − 160) / (170 − 20) = −0.93
Both slopes are inside [−1.50, −0.60].
"Phoenix|10,200|110,50|160,20" "Phoenix, Entry Corridor Approved!" mstart = (50 − 200) / (110 − 10) = −1.50 (Exact boundary!)
mend = (20 − 200) / (160 − 10) = −1.20
Both slopes are inside [−1.50, −0.60].
"Valkyrie|50,200|90,40|150,20" "Valkyrie, Abort Trajectory!" mstart = (40 − 200) / (90 − 50) = −4.00 (Too steep!)
mend = (20 − 200) / (150 − 50) = −1.80 (Too steep!)
"Curiosity|40,180|140,80|240,110" "Curiosity, Abort Trajectory!" mstart = (80 − 180) / (140 − 40) = −1.00 (Valid)
mend = (110 − 180) / (240 − 40) = −0.35 (Too shallow!)
