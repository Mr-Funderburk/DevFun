Iteration

Overview

When programming, you will frequently need to repeat a block of code multiple times. While functions eliminate duplicated code across different parts of a program, iteration (looping) allows a single block of code to run repeatedly based on a condition or collection size.

repetitive_code.py
Python 
# Manual printing without loops becomes unmanageable quickly:
all_fruit = ["apple", "avocado", "blackberry", "blueberry", "cherry", "strawberry"]

print(all_fruit[0])
print(all_fruit[1])
print(all_fruit[2])
# ... manual lines required for every single element!

Using loops cuts down on repetitive code, simplifies maintenance, and dynamically adapts when items are added or removed from data collections.

Core Concepts: Three Loop Structures

  • For-Each (Enhanced For): Direct iteration through each element in a collection.
  • Standard For: Index-driven or range-driven iteration using numerical steps.
  • While: Condition-driven iteration that repeats as long as a boolean expression evaluates to True.

1. For-Each Loop (Enhanced For)

Python's primary loop structure is designed to iterate through collections directly. A temporary variable holds the value of the current element for each cycle through the collection.

for_each.py
Python 
all_fruit = ["apple", "avocado", "blackberry", "blueberry", "cherry"]

# Syntax: for [temporary variable] in [collection]:
for fruit in all_fruit:
    print(fruit)

# Iteration 1: fruit = "apple"
# Iteration 2: fruit = "avocado"
# Iteration 3: fruit = "blackberry" ...

The temporary variable (fruit) is local to the loop body and automatically updates to point to the next item in sequence until the entire collection has been traversed.

Remember: Since this temporary variable has a local scope, when the for each loop is done, the temporary variable is no longer accessable.

2. The range() Function

Before using index-based loops, you need to understand the built-in range() generator. It produces sequence values based on up to three integer arguments:

range_syntax.py
Python 
range(stop)              # Starts at 0, counts up to (stop - 1)
range(start, stop)       # Starts at start, counts up to (stop - 1)
range(start, stop, step) # Starts at start, increments/decrements by step
  • stop (Required): The ending boundary. The stopping point is exclusive (it counts up to, but never includes, this value).
  • start (Optional): The initial integer. Defaults to 0 if omitted.
  • step (Optional): The amount added or subtracted per iteration. Defaults to 1 if omitted.

3. Standard For Loop

Combining for with range() creates a standard numeric loop. In Python, the loop counter is conventionally named i (short for index or iteration).

standard_for.py
Python 
all_fruit = ["apple", "avocado", "blackberry", "blueberry", "cherry"]

# Accessing list elements using zero-based indexing via range(len(...))
for i in range(len(all_fruit)):
    print(all_fruit[i])

Advanced Range Operations

By adjusting start, stop, and step parameters, you can traverse collections in reverse or skip elements:

range_traversals.py
Python 
# Example 1: Reverse Traversal
# Starts at last index (len - 1), ends at -1 (exclusive, so stops at 0), step is -1
for i in range(len(all_fruit) - 1, -1, -1):
    print(all_fruit[i])

# Example 2: Skip Every Other Item
# Starts at index 0, ends at len (exclusive), step is 2
for i in range(0, len(all_fruit), 2):
    print(all_fruit[i])

4. While Loop

A while loop executes repeatedly as long as its conditional statement remains True. You must ensure the loop state changes within the body to prevent an infinite loop.

while_loops.py
Python 
# Incorrect: Infinite Loop (i is never updated)
i = 3
while i < 10:
    print(13 + i)  # Never stops because i remains 3!

# Correct: Condition state updates each iteration
i = 3
while i < 10:
    print(13 + i)
    i += 1  # Increment ensures i reaches 10 to exit

Forever Loops

While the above examples showcase situations where you do not want your loops to continue forever, there are instances when you do want your code to run forever (or at least until the user picks to stop).

This could include a game (the game continues to run until the user stops it), or an application (a paint program on your computer runs until you close it), and many others.

We can use a while loop for this and set our condition to True. Since True is always True, the code will run forever! Just be sure there is some way to end your program! (Keep reading to find out how!)

while_loops.py
Python 
while True:
    # execute some code forever!

Choosing the Right Loop

Loop Comparison Table
Loop Type When to Use Key Characteristic
for each Traversing a collection directly without needing index positions. Cleanest syntax; automatically stops at collection end.
standard for Known iteration count, reverse steps, or index-specific operations. Uses numerical indices; controlled by range() limits.
while Unknown number of iterations (e.g., waiting for user input, game loops). Repeats purely based on boolean condition state.

Loop Control: break and continue

Python provides two control flow statements to alter loop execution dynamically:

  • break: Immediately terminates the loop block completely.
  • continue: Skips the remainder of the current iteration and jumps directly to the next iteration cycle.
loop_controls.py
Python 
# Example 1: Exiting early with break
numbers = [3, 7, 12, 5, 20]
for num in numbers:
    if num > 10:
        print("First number over 10 found:", num)
        break  # Exits loop immediately

# Example 2: Skipping cycles with continue
for num in range(1, 6):
    if num == 3:
        continue  # Skips printing 3
    print(num)    # Output: 1, 2, 4, 5

It is important to point out as well that the return keyword in a function will stop a loop as well.

  2. Write a for-each loop that prints every string in a list named cities in uppercase using .upper().
  3. Convert a standard index-based loop into a while loop that counts down from 10 to 1.
  4. Explain the difference between what happens when break is triggered versus when continue is triggered inside a loop.
