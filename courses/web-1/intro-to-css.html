Intro to External CSS

The Invisible Power: Disabling CSS

HTML builds the skeleton of a web page, but Cascading Style Sheets (CSS) gives it life. Without CSS, even multi-billion dollar websites look like standard text files written in 1995.

Let's perform a live experiment to see just how much heavy lifting CSS actually does behind the scenes.

Interactive Demonstration: Strip Away the Styles

  1. Open any major website in Google Chrome (e.g., Wikipedia or TIME).
  2. Right-click anywhere on the page and select Inspect to open Developer Tools.
  3. Press Ctrl + Shift + P (Windows) or Cmd + Shift + P (Mac) to open the Command Menu.
  4. Type Block and select Show Network Request Blocking.
  5. Click the + button, enter *.css, click Add, and refresh the page!

Notice how instantly flat, raw, and unstyled the web page becomes? That raw outline is pure HTML! Everything else—layouts, colors, spacing, alignment, and fonts—is controlled entirely by CSS.

Connecting an External Stylesheet

While CSS can be written directly inside HTML tags, professional web developers almost exclusively use External CSS. This involves placing all styling rules in a standalone .css file and linking it to HTML pages.

To connect an external stylesheet, add a <link> element inside the <head> tag of your HTML document:

index.html
HTML 
<head>
    <title>My Styled Page</title>
    <link rel="stylesheet" href="css/style.css">
</head>

The <link> element is a void tag (no closing tag needed) and relies on two essential attributes:

  • rel="stylesheet": Tells the browser that the linked document is a CSS style sheet.
  • href="css/style.css": Specifies the relative path to your CSS file. (Usually kept in a dedicated folder)

Anatomy of a CSS Rule

CSS follows a specific syntax structured around target selection and declaration blocks. A single styling rule consists of three core components:

style.css
CSS 
h1 {
    color: #38bdf8;
    background-color: #151d32;
}

Breaking Down the Syntax

  • Selector (h1): Tells the browser which HTML element(s) to style. In this case, all <h1> headers on the page.
  • Property (color, background-color): Defines what aspect of the element you want to change (e.g., text color, background fill).
  • Value (#38bdf8, #151d32): Specifies how the property should be changed.
  • Declaration Block ({ ... }): Curly braces contain one or more property-value pairs. Each declaration MUST end with a semicolon (;)!

Starting Small: Colors & Borders

Let's explore three fundamental CSS properties that allow us to customize elements right out of the gate:

1. Font Color (color)

Controls the foreground color of text content inside an element.

p { color: white; }

2. Background Color (background-color)

Fills the box behind an element with a solid color. You can use standard color names (red, blue), Hexadecimal codes (#ff0000), or RGB values (rgb(255, 0, 0)).

body { background-color: #0b1020; }

3. Borders (border)

Draws a bounding line around an element. The border property requires three values in order: width, style, and color.

h2 { border: 2px solid #7ee787; }

Visualizing Layouts with CSS Debugging

In our last lesson, we learned about semantic layout tags like <header>, <main>, <article>, and <footer>. Remember how we said they don't look like anything on screen by default?

We can use background colors and temporary borders to "debug" our web page layouts. Adding distinct styles to semantic containers reveals where each box sits on the screen and how elements nest inside one another!

Create a new folder in web-1/learning/ called css. Create a file called fan-page.css inside your web-1/learning/css/ folder and add the following CSS to style your previous fan-page.html file:

fan-page.css
CSS 
/* General Page Styling */
body {
    background-color: #0b1020;
    color: #f4f7fb;
}

/* Header & Navigation Layout Visualizer */
header {
    background-color: #151d32;
    border: 2px solid #6d7cff;
}

/* Main Content Area */
main {
    background-color: #11182b;
    border: 2px dashed #38bdf8;
}

/* Individual Articles */
article {
    background-color: #1b2640;
    border: 2px solid #7ee787;
}

/* Footer Section */
footer {
    background-color: #151d32;
    border-top: 3px solid #fbbf24;
}

Once linked, refresh fan-page.html in your browser. Every invisible semantic block is now clearly visible with its own colored border and bounding box!
