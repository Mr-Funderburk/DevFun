// About DevFun

Programming is complex.
Learning it shouldn't be.

DevFun is my classroom on the open web. The name is one part development, one part my last name — Funderburk — which my students shortened to "Mr. Fun" years ago and never gave back.

Classroom Tenets

  • You will write code every single day. Watching is not learning.
  • Broken code is normal. Reading the error message is the skill.
  • Ask for help early and often — after you have actually tried something.
  • If you cannot explain your code, it is not your code yet.

This website is a collection of computer science courses designed to help students learn by doing: writing code, solving problems, and building real projects.

Created and curated by Stephen "Mr. Fun" Funderburk, all original course materials are shared under the MIT License.
