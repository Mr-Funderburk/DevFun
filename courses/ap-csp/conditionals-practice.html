Practice Set: Python Conditionals

Test your understanding of basic if/else statements, elif chains, compound conditions (and, or, not), and Boolean variable rules. Write Python code segments to solve each of the following scenarios.

Easy Problems

Problem 1: Even or Odd

Write a code segment that takes an integer variable named number. If the number is even, print "Even". Otherwise, print "Odd". (Hint: Use the modulus operator %).

Problem 2: Passing Grade

Write a code segment that evaluates an integer variable score. If score is 60 or higher, print "Passed". If it is less than 60, print "Needs Improvement".

Problem 3: Clean Boolean Check

Given a Boolean variable is_logged_in = True, write an if/else statement that prints "Welcome back!" if logged in, and "Please sign in." if not.

Medium Problems

Problem 4: Temperature Dress Code

Write a code segment using an if-elif-else structure that checks a variable temp (integer) and prints a recommendation based on the following rules:

  • Below 50: Print "Wear a heavy coat"
  • 50 to 75 (inclusive): Print "Wear a light jacket"
  • Above 75: Print "Shorts weather!"

Problem 5: Movie Discount Eligibility

A movie theater offers discounts for children and seniors. Given two variables, age (integer) and has_student_id (Boolean), print "Discount Rate" if the customer's age is under 12 OR 65 and older, OR if has_student_id is True. Otherwise, print "Regular Price".

Problem 6: Two-Factor Login Authenticator

Given three variables: username (string), password (string), and auth_code (integer), write a single if/else condition using logical operators that prints "Access Granted" ONLY if:

  • username equals "admin" AND
  • password equals "secret123" AND
  • auth_code equals 9999

Otherwise, print "Access Denied".

Problem 7: Weekend Rain Checker

Given the variables day (string) and is_raining (Boolean), write a code segment that prints "Stay inside and read" if it is the weekend ("Saturday" or "Sunday") AND it is raining. Otherwise, print "Go outside!".

Hard Problems

Problem 8: Roller Coaster Restrictions

A theme park ride has strict safety standards. To ride, a guest must meet the following requirement:

  • They must be at least 48 inches tall.
  • AND they must either be 12 years or older OR accompanied by an adult (represented by a Boolean variable with_adult).

Write a code segment using the variables height, age, and with_adult that prints "Boarding permitted" if eligible, and "Cannot ride" if not.

Problem 9: DeMorgan's Simplification Challenge

Consider this condition:

main.py 
if not (score >= 70 and attendance >= 80):
    print("Action required.")

Use DeMorgan's Laws to rewrite this if condition into an equivalent form without using the surrounding not(...) wrapper.

Problem 10: Leap Year Determiner

Write a Python program segment to determine whether an integer variable year represents a leap year. The rules for a leap year are:

  • The year must be evenly divisible by 4.
  • EXCEPT if it is also divisible by 100, it is not a leap year—UNLESS it is also evenly divisible by 400.

Print "Leap Year" or "Standard Year" based on the value of year. (Test case: 2000 was a leap year, 1900 was not, 2024 was a leap year).
