Python Collections

Overview

A collection is an aggregate set of data. Collections are objects that group multiple elements into a single unit. Common real-world examples include a deck of playing cards (each card is distinct, but together they form a deck), contacts on your phone, or an email inbox.

Python provides four general-purpose, built-in collections: tuple, list, dict (dictionary), and set.

Core Concepts: Mutability

  • Mutable: Able to be changed after creation.
  • Immutable: Cannot be changed after creation.

Strings are immutable. When you reassign a string variable, Python creates a new string in memory rather than modifying the existing one. Immutable data types are generally faster and safer, while mutable data types offer flexibility.

Tuple

A tuple is an ordered, indexed, and immutable collection that allows duplicate values. Tuples are defined using parentheses ().

collections.py
Python 
domestic = ("cat", "dog")
animal_tuple = (domestic, "eagle", "cow")

print(animal_tuple)
# Output: (('cat', 'dog'), 'eagle', 'cow')

# Accessing items via zero-based indexing
print(animal_tuple[1])
# Output: eagle

Since tuples are immutable, items cannot be added, removed, or changed once defined. Like strings, Python supports negative indexing on tuples to count backward from the end (e.g., [-1] accesses the last item).

List

A list is an ordered, indexed, and mutable collection that allows duplicate values. Lists are defined using square brackets [].

collections.py
Python 
# == List Example == #
domestic = ["cat", "dog"]
animal_list = [domestic, "eagle", "cow"]

print(animal_list)
# Output: [['cat', 'dog'], 'eagle', 'cow']

# Modifying elements in a list
animal_list[1] = "hawk"
print(animal_list)
# Output: [['cat', 'dog'], 'hawk', 'cow']

Because lists are mutable, elements can be dynamically altered throughout program execution. Use tuples when data should remain constant and secure; use lists when data needs to change.

Essential List Methods

Python provides built-in methods to modify list elements directly without replacing the entire collection:

collections.py
Python 
inventory = ["shield", "potion"]

# .append(item) - Adds an item to the end of the list
inventory.append("sword")
print(inventory)  # Output: ['shield', 'potion', 'sword']

# .remove(value) - Removes the first matching item by value
inventory.remove("potion")
print(inventory)  # Output: ['shield', 'sword']

# .pop(index) - Removes and returns an item at a given index (defaults to last)
last_item = inventory.pop()
print(last_item)   # Output: sword
print(inventory)   # Output: ['shield']

Dict (Dictionary)

A dictionary stores data in key-value pairs. Dictionaries are ordered (as of Python 3.7+), mutable, and do not allow duplicate keys. Dictionaries are defined using curly braces {} with colon-separated key-value pairs.

collections.py
Python 
# == Dictionary Example == #
animal_dict = {
    "domestic": ["cat", "dog"],
    "wild": ["tiger", "penguin"],
    "favorite": "eagle"
}

print(animal_dict["wild"])
# Output: ['tiger', 'penguin']

# Adding a new key-value pair or updating an existing one
animal_dict["mascot"] = "cougar"
print(animal_dict["mascot"])
# Output: cougar

Instead of integer indexes, dictionaries use unique keys to access values. Keys must be an immutable type (like strings, integers, or tuples containing only immutable types).

Set

A set is an unordered, unindexed, and mutable collection that does not allow duplicate values. Sets are defined using curly braces {}. To create an empty set, you must use set(), as {} defaults to an empty dictionary.

collections.py
Python 
# == Set Example == #
domestic = {"dog", "cat", "fish"}
wild = {"wolf", "tiger", "fish"}

# Set Mathematical Operations
print(domestic | wild)  # Union: {'cat', 'tiger', 'fish', 'wolf', 'dog'}
print(domestic & wild)  # Intersection: {'fish'}
print(domestic - wild)  # Difference: {'cat', 'dog'}
print(domestic ^ wild)  # Symmetric Difference: {'tiger', 'wolf', 'dog', 'cat'}

Common Collection Tools

1. Collection Size with len()

The built-in len() function counts the total number of items stored inside any Python collection.

collections.py
Python 
my_tuple = (10, 20, 30)
my_dict = {"a": 1, "b": 2}

print(len(my_tuple))  # Output: 3
print(len(my_dict))   # Output: 2 (counts key-value pairs)

2. Membership Operators (in and not in)

You can check if an item exists within a collection without writing loops by using the in and not in boolean operators.

collections.py
Python 
guests = ["Alice", "Bob", "Charlie"]
user = "David"

if user not in guests:
    print("Access denied.")

# Works with dictionary keys directly:
credentials = {"admin": "secret123"}
if "admin" in credentials:
    print("User found.")
