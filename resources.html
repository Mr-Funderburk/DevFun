VS Code

Visual Studio Code (commonly known as VS Code) is a free, open-source, and lightweight source code editor developed by Microsoft. It is designed for cross-platform use on Windows, macOS, and Linux, offering a fast, responsive environment for writing and debugging code.

PyCharm

PyCharm is an Integrated Development Environment (IDE) developed by JetBrains specifically for Python programming. It provides a comprehensive suite of tools to help developers write, debug, test, and deploy code efficiently, making it one of the most popular choices for Python, web development, and data science.

AP CSP

IntelliJ

IntelliJ IDEA is a professional Integrated Development Environment (IDE) developed by JetBrains primarily for Java and Kotlin development, though it supports other JVM-based languages like Scala and Groovy, as well as web and mobile technologies. It is designed to maximize developer productivity through intelligent code completion, static code analysis, and powerful refactoring tools that understand code context.

AP CSA

GameMaker Studio

GameMaker Studio is a cross-platform game development engine designed primarily for creating 2D games, developed by YoYo Games since 2007. It features an intuitive interface that supports both drag-and-drop visual programming for beginners and a custom scripting language called GameMaker Language (GML) for advanced developers.

Godot

Godot is a free and open-source game engine used to create 2D and 3D games and applications for desktop, mobile, web, and console platforms. Released publicly in 2014 under the permissive MIT License, it allows developers to own their entire project with no royalties or licensing fees.
