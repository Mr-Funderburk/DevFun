Project: Event Page

Project Overview

This project synthesizes everything you have learned in class so far: clean file architecture, semantic HTML structure, the CSS Box Model, class-based component design, and interactive pseudo-class states.

You will create a high-impact, single-page promotional landing page for an event of your choice. Choose an event topic that excites you, such as:

  • Esports / Gaming Tournament (e.g., Retro Arcade Showdown or Valorant Campus Clash)
  • Local Concert or Music Festival (e.g., Indie Rock Night or Summer Beats Fest)
  • Food Truck & Culinary Festival (e.g., Street Eats & Brews Expo)
  • Charity Fundraiser or Community Run (e.g., 5K Rescue Paws Marathon)

Technical Requirements Checklist

Review the technical requirements below to ensure your landing page satisfies every grading criteria:

1. File & Semantic HTML Structure

  • Clean File Architecture: Create a dedicated project folder and image assets directory using strict kebab-case naming (e.g., projects/event-page/img/event-banner.jpg).
  • Semantic Tag Blueprint: Structure your code cleanly with semantic tags including <header>, <nav>, <main>, <article>, and <footer>.
  • Strict Indentation: Maintain clean parent-child nesting throughout index.html (2 or 4 spaces per nesting level).
  • Heading Hierarchy: Include exactly one main <h1> tag for the primary event title, <h2> tags for major section titles, and <h3> tags for sub-cards or individual items.
  • Structured List Component: Include at least one <ul> or <ol> list detailing event rules, a schedule, ticket tiers, or featured speakers/performers.

2. CSS Classes & Component Design

  • External Stylesheet: Link an external stylesheet (e.g., style.css) inside the HTML <head>. Internal style blocks or inline style attributes are prohibited.
  • Class-Based Styling: Style reusable UI cards and layout components using clean CSS class selectors.
  • Modifier Classes: Include at least one modifier class applied to a specific component to alter its visual layout or accent colors (e.g., <article class="card card-featured"> or <div class="info-box info-featured">).

3. Interactive Elements & Accessibility

  • Interactive Hover States: Write distinct CSS :hover pseudo-class rules for all interactive links/buttons and at least one non-button container element (e.g., changing background color, border highlight, or box-shadow on card mouseover).
  • Descriptive Image Alt Text: Provide detailed, descriptive alt text for every image element (e.g., alt="Crowd cheering at outdoor indie music stage during sunset").

Project Point Breakdown Rubric

Grades will be awarded based on the technical evaluation matrix below:

Grading Rubric Matrix
Criteria Requirement Overview Points

Semantic Tag Architecture Complete usage of <header>, <nav>, <main>, <article>, and <footer> with clean parent-child indentation. 25 pts
Heading & List Hierarchy Strict heading levels (single <h1>, section <h2>, card <h3>) plus an organized <ul>/<ol> list. 20 pts
Component & Modifier Classes Structured CSS class selectors featuring at least one functional modifier class (e.g. .ticket-card-featured). 20 pts

Step-by-Step Submission Instructions

  1. Directory Creation: Create a root project directory named projects/event-landing/. Inside, create an img/ subfolder for your event image assets.
  2. Image Setup: Download relevant high-quality images, save them inside img/ using lowercase kebab-case filenames (e.g., concert-stage.jpg), and add descriptive alt text in HTML.
  3. Markup Construction: Create index.html. Build out the landing page sections adhering to the strict heading hierarchy and semantic HTML requirements.
  4. Component Styling: Create style.css. Style your layout, apply a modifier class to bring visual hierarchy to a featured section, and craft smooth :hover transitions.
  5. Interactive Testing: Open your browser, move your cursor across links and cards to verify hover animations, and inspect elements to confirm no box-model overlaps exist.
