1. RPG Battle Simulator & Combat Log

Students build an interactive text-based battle simulator where a player fights a monster turn-by-turn. They manage player inventory, log damage dealt in each round to a list, and analyze combat statistics after the battle finishes.

Project Milestones:

  1. Pre-Battle Countdown
    Use a standard for loop with a negative step counter to countdown from 3 to 1.
  2. Main Combat Loop
    Create a while loop that continues as long as both player_hp > 0 and monster_hp > 0. Each round:
    • Prompt the player to attack or use an item.
    • Calculate random damage and subtract it from the monster or player.
    • Track round numbers using a simple vounter variable.
  3. Inventory Display
    If the player chooses to view their inventory, it should iterate through the collection using a standard for loop, printing the slot number with the item name.
  4. Post-Battle Damage Analysis
    Store every damage value dealt to the monster in a list called damage_history. After the main loop concludes, iterate through the history to compute:
    • Total damage dealt
    • Average damage dealt
    • Highest single hit
    • Number of critical hits (hits over 17 damage)

Project Milestones:

  1. 7-Day Data Collection Loop

  2. Input Validation Loop
    Inside the daily loop, nest a while loop that forces the user to re-enter a step count if they enter a negative number or non-numeric input.

    • [GOAL MET] if steps are STEP_GOAL or more.

  4. Weekly Performance Metrics
    Iterate through step_log to calculate and output:
    • Total weekly steps.

3. Smart ATM & Transaction History Manager

Students build a banking terminal program that enforces a 3-attempt PIN login, maintains a running account balance, processes deposits and withdrawals using a transaction history list, and prints itemized statements.

Project Milestones:

  1. Security PIN Verification
    Allow the user up to 3 attempts to enter a correct PIN using a for loop. If they fail all 3 tries, terminate the program with an account lock message.
  2. Interactive Menu System
    Once authenticated, launch a while loop that displays a menu:
    1. Deposit Funds
    2. Withdraw Funds
    3. Print Statement
    4. Exit
  3. Transaction Log Display
    Store deposits as positive floats (e.g., 100.0) and withdrawals as negative floats (-25.50) in a transactions list. When option 3 is selected, iterate through transactions using a for loop to print each itemized transaction with its index number.
  4. Audit & Security Summary
    Add an advanced audit feature to option 3 that iterates through transactions to calculate:
    • Total amount deposited
    • Total amount withdrawn.
    • Number of withdrawals greater than $100.00.
