Media Queries & Mobile-First Design

Building for Every Screen Size

Over half of all web traffic worldwide originates from mobile devices. Responsive Web Design (RWD) is the practice of building websites that gracefully adapt their layout, text sizing, and media elements to fit screen sizes ranging from small smartphones to massive desktop monitors.

1. The Critical Viewport Meta Tag

By default, mobile browsers assume every website is designed for desktop screens around 980 pixels wide. To compensate, mobile browsers zoom out, making text and images appear tiny and unreadable unless forced to pinch-and-zoom.

To tell smartphones to render your page at the device's actual physical screen width, you must always include the viewport meta tag inside your HTML <head>:

index.html
HTML 
<!-- Required for responsive CSS scaling on mobile screens -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

2. What, Why, and How: Media Queries

A Media Query is a CSS rule that applies a block of styles only if specific condition criteria (such as browser viewport width) are met.

media-query-syntax.css
CSS 
/* Base styles (Default for small screens) */
.container {
    background-color: #0f172a;
    padding: 16px;
}

/* Media Query: Applied only when screen width is 768px or wider */
@media (min-width: 768px) {
    .container {
        background-color: #1e293b;
        padding: 32px;
    }
}
Common Screen Breakpoints
Device Target Breakpoint Rule Layout Shift Strategy
Mobile Phones Default Styles (No Query) Single-column stacked elements, full width.
Tablets & Large Phones @media (min-width: 600px) 2-column grids, moderate spacing.
Laptops & Desktops @media (min-width: 900px) 3 or 4-column grids, visible sidebars.

3. Mobile-First Design Theory

Mobile-First Design is a strategy where you write your primary CSS styles for small mobile screens first, and then use min-width media queries to layer on complex multi-column layouts as screen space increases.

Why Design Mobile-First?

  • Cleaner CSS: Overriding complex multi-column desktop layouts to fit mobile screens creates bloated code. Expanding a clean 1-column layout upward requires much less CSS.
  • Faster Mobile Loading: Mobile devices process fewer lines of code because they don't load desktop layout overrides.

4. Responsive Images

We can create responsive images (among other elements) using object-fit to tell the browser how we want to fit the element in the parent. Consider the following example:

object-fit.html
HTML 
<div class="fit-image">
    <img src="img/my-image.jpg" alt="Description of my image">
</div>
object-fit.css
CSS 
.fit-image {
    border: 2px solid #f0f;
    width: 50%;
    margin: 0 auto;
    height: 100px;
}

.fit-image img {
    width: 100%;
    height: 100%;
    object-fit: cover;
}

Try changing the value of the object-fit property to contain or fill!

5. Showing & Hiding Elements across Devices

Not all desktop content belongs on mobile. You can use display: none; alongside media queries to hide mobile navigation toggles on desktop, or remove bulky desktop banners on small screens.

show-hide.css
CSS 
/* Hide mobile menu button on desktops */
.mobile-nav-btn {
    display: block; /* Visible by default on mobile */
}

@media (min-width: 768px) {
    .mobile-nav-btn {
        display: none; /* Hidden on desktop screens */
    }
}

/* Hide desktop banner on small mobile devices */
.desktop-banner {
    display: none; /* Hidden by default on mobile */
}

@media (min-width: 768px) {
    .desktop-banner {
        display: block; /* Shown only on desktop */
    }
}

Student Hands-On Exercise: Fix the Broken Page

The code snippet below is a broken, non-responsive webpage! When viewed on a smartphone, the fixed pixel widths cause severe horizontal scrolling, squeezed images, and unreadable text.

Your Task: Copy the broken code into your code editor and perform these 4 fixes:

  1. Add the missing <meta name="viewport"> tag inside the HTML <head>.
  2. Fix the broken image rule so images scale fluidly (replace fixed width with max-width: 100%; height: auto;).
  3. Convert fixed container pixel widths (width: 960px) to responsive percentage rules or Flexbox layouts.
  4. Add a media query at min-width: 768px to switch the stacked mobile layout into a side-by-side row.
broken-page.html
HTML (Broken)

<html lang="en">
<head>
    <meta charset="UTF-8">
    <!-- BUG 1: Missing viewport meta tag! -->

        body {
            background-color: #0b1020;
