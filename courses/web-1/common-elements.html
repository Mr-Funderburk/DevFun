Common Elements

Heading Hierarchy

You already know <h1> is the main title of a web page. HTML gives us six levels of headings: <h1> through <h6>. As the number goes up, the structural importance (and default size) goes down.

  • <h1> — Main Page Heading (Limit to one per page)
  • <h2> — Major Section Headers
  • <h3> — Sub-sections inside an h2
  • <h4> to <h6> — Lower-level sub-headings

Rule of Thumb: Never skip heading levels just to change font size! Don't jump from an <h2> straight to an <h4>. Treat headings like a book outline.

Text Formatting Tags

We've used <strong> to make text bold and visually important. Here are three more tags for refining your text:

  • <em> — Emphasis tag. Renders text in italics and signals to screen readers to stress that word.
  • <mark> — Highlight tag. Renders a bright yellow background behind text to indicate relevance or focus.
  • <small> — Side-comment tag. Makes text slightly smaller—perfect for copyright notices, legal disclaimers, or fine print.

Lists: Unordered & Ordered

Web content relies heavily on lists. HTML provides two main list types. Both require child <li> (List Item) tags inside them to represent each item.

Unordered Lists (<ul>)

Use when item order does not matter (like a grocery list or feature list). Renders bullet points by default.

common-elements.html
HTML 
<ul>
    <li>Apples</li>
    <li>Bananas</li>
</ul>

Ordered Lists (<ol>)

Use when sequence or order matters (like step-by-step instructions or top 10 rankings). Renders numbers by default.

common-elements.html
HTML 
<ol>
    <li>Preheat oven</li>
    <li>Bake for 20 mins</li>
</ol>

Dividers & Line Breaks

Sometimes you need to control spacing or create section breaks without wrapping text in new paragraphs:

  • <hr> — Horizontal Rule. Creates a thematic break across the page (a thin horizontal line). It is a void element (no closing tag needed!).
  • <br> — Line Break. Forces text onto a new line inside a paragraph without starting an entirely new paragraph block. It is also a void element.

Putting It Together

In your web-1/learning/ folder, create a new file named common-elements.html. Add the following code and test it out in your web browser:

common-elements.html
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Common HTML Elements</title>
</head>
<body>
    <h1>The Developer's Handbook</h1>
    <p>Learning web development requires <em>patience</em>, practice, and curiosity.</p>

    <hr>

    <h2>Top Hobbies</h2>
    <ul>
        <li>Coding HTML pages</li>
        <li>Playing video games</li>
        <li><mark>Learning new skills</mark></li>
    </ul>

    <h2>Morning Routine</h2>
    <ol>
        <li>Turn off alarm</li>
        <li>Drink a glass of water</li>
        <li>Open VS Code</li>
    </ol>

    <p>Line 1 of text<br>Line 2 directly below it!</p>

    <small>&copy; 2026 Web Development 1 Student. All rights reserved.</small>
</body>
</html>

Self-Closing / Void Tags

Notice how <hr> and <br> don't have closing tags like </hr>? Tags that cannot hold content inside them are called void elements and don't require a closing tag.

Challenge: Uncover the Mystery Tags

There are several other useful HTML elements that don't need attributes to function, but we haven't covered them yet! Your task is to research and add at least three of the following unmentioned tags into your common-elements.html file:

  1. Find a tag used to represent deleted/strikethrough text (great for showing discounts or edits).
  2. Find a tag used to represent inserted/underlined text.
  3. Find a pair of tags used to render subscript (like chemical formulas: H2O) and superscript (like exponents: 102).
  4. Find a tag used to display computer code snippets inside a standard paragraph block.

Add these new elements to your page, save, and refresh your browser to see what they look like in action!
