Practice Your Positioning Skills!

1. Notification Bell Counter

Goal: Create a button with a floating numeric alert badge on its top-right corner.

  • HTML Task: Create a hyperlink (<a href="#" class="messages-button">Messages</a>) containing a badge span (<span class="badge">3</span>).
  • CSS Task:
    1. Set .messages-button to have a relative position.
    2. Set .badge to have an absolute position with a top and right offset of -8px.
    3. Style the badge into a small red circle with white centered text.
    4. Apply extra styles to make the link look like a button. Be sure to add the pseudo-classes as well (:link, :visited, :hover, :focus, :active)

2. Image Banner Text Overlay

Goal: Darken the bottom of an image and overlay a title cleanly across it.

  • HTML Task: Create a div with a banner class applied. Inside the div, add an image of your choice, but make sure the image takes up the entire width and height of the banner div you just created. Then, create an h2 with the class banner-title. Add any title text you would like.
  • CSS Task:
    1. Set the banner class's position to relative and add the declaration overflow: hidden; to hide any part of the image that doesn't fit into the div. Give the div a specified height.
    2. Set the banner-title to have an absolute position with the bottom, left, and right properties set to zero.
    3. Give the banner-title a semi-transparent background color using rgba(0, 0, 0, 0.75);. Change the text color to white and increase the padding.

3. Back-to-Top Button

Goal: Create a floating "Back to Top" link that stays in the bottom right corner of the screen, regardless of if the user scrolls the page. Add styles to the link to make it pretty.

4. Floating Header

  • HTML Task: Create a header on your page the is not at the top of your screen.
  • CSS Task:
    1. Set the position of the header to sticky. When the header reaches the top, it should stick to the top of the viewport. Ensure that there is ample space added at the bottom of your page to allow the page to scroll down.
