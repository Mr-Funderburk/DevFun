Python Strings & Text Manipulation

A string is a sequence of characters—including letters, numbers, symbols, and spaces. In Python, strings are wrapped in either single quotes ('...') or double quotes ("..."). Both methods are functionally identical in Python, but alternating between them lets you easily embed quotes inside text.

strings.py
Python 
# Single quotes allow unescaped double quotes inside
quote_one = 'She said, "Canterbury School is the best!"'

# Double quotes allow unescaped single quotes/apostrophes inside
quote_two = "I'd say I don't like that, but I can't."

Java / AP CSA Note:

While Python allows both single and double quotes, many languages (like Java and C++) strictly reserve single quotes for individual characters (char) and double quotes for full text strings. If you plan to take AP Computer Science A (Java), habituating double quotes now makes for a smoother transition.

String Concatenation & Explicit Type Casting

Joining strings end-to-end is called concatenation, which is performed using the + operator. Python requires both operands in a concatenation expression to be strings. Attempting to concatenate a string with an integer or float directly results in a TypeError.

To join numeric data with text, you must explicitly cast the variable using the str() function:

strings.py
Python 
state = "Florida"
print("You selected " + state) # Valid concatenation

score = 95

# ERROR: Python cannot implicitly combine str and int
# print("Your score is " + score) 

# VALID: Explicitly cast score to a string first
print("Your score is " + str(score))

Escape Characters

An escape character is a backslash (\) followed by a specific character. It tells Python to treat the following character as a special instruction rather than plain literal text.

Escape SequenceMeaning / ActionExample Usage
\"Escaped Double Quote"She said, \"Hello!\""
\'Escaped Single Quote'It\'s a sunny day'
\nNew Line (Line Break)"Hello\nWorld"
\tTab Space (Indent)"Item:\tPrice"
\\Literal Backslash"C:\\Users\\Python"
strings.py
Python 
# Formatting output with line breaks and tabs
print("Shopping List:\n\t1. Apples\n\t2. Bread")

# Output:
# Shopping List:
# 	1. Apples
# 	2. Bread

Essential String Methods

Python provides built-in methods to analyze and modify string contents. Because strings in Python are immutable (cannot be changed in place), methods return a new string rather than altering the original variable.

1. Case Conversion: .upper(), .lower(), .capitalize(), and .title()

.upper() and .lower() converts all characters in the target string to uppercase or lowercase, respectively. Useful for standardizing user input before comparison.

.capitalize() will convert all characters to lowercase, with the exception of the first word, which will have a capitalized first letter.

.title() will convert all characters to lowercase and then capitalize the first letter of each word.

strings.py
Python 
text = "Python is Fun"
print(text.upper()) # "PYTHON IS FUN"
print(text.lower()) # "python is fun"
print(text.capitalize()) # "Python is fun"
print(text.title()) # "Python Is Fun"

2. Whitespace Removal: .strip()

Removes leading and trailing whitespace (spaces, tabs, newlines) from the edges of a string.

strings.py
Python 
user_input = "   user@example.com  \n"
clean_input = user_input.strip()
print(clean_input) # "user@example.com"

3. Replacing Substrings: .replace()

Replaces all occurrences of a target phrase with a replacement phrase. An optional third parameter caps the total number of replacements performed.

strings.py
Python 
phrase = "English is fun"
print(phrase.replace("English", "Python")) # "Python is fun"

4. String Length: len()

The built-in function len() counts every character inside a string, including letters, numbers, symbols, and spaces.

strings.py
Python 
message = "Python is fun"
print(len(message)) # 13

String Indexing: Character Positions

To extract specific characters or perform slicing, you must understand how Python tracks character locations. In programming, the location of each character inside a string is called its index.

Python uses zero-based indexing, meaning it begins counting positions at 0 rather than 1.

Golden Rule of Indexing:

"The index is always the count minus one!"

  • The 1st character is at index 1 - 1 = 0
  • The 5th character is at index 5 - 1 = 4
  • The 10th character is at index 10 - 1 = 9
  • If a string has a length/count of N characters, its final character is at index N - 1.

Visual Index Map

Consider the string "PYTHON" (which has a total length of 6 characters):

Character P Y T H O N
Human Count (Position) 1st 2nd 3rd 4th 5th 6th
Python Index (Count - 1) 0 1 2 3 4 5

Accessing Individual Characters

Use square brackets [ ] directly after a string variable to access the character at a specific index.

strings.py
Python 
word = "PYTHON"

# Access the 1st character (Count 1 - 1 = Index 0)
first_letter = word[0] # "P"

# Access the 4th character (Count 4 - 1 = Index 3)
fourth_letter = word[3] # "H"

# Access the last character using len() - 1
last_index = len(word) - 1
last_letter = word[last_index] # "N" (Index 5)

print(first_letter + fourth_letter + last_letter) # Outputs: PHN

Watch out for IndexErrors: If you try to access an index equal to or greater than the string's total length (e.g., word[6] on a 6-character string), Python will crash with an IndexError: string index out of range because index 6 would represent a nonexistent 7th character!

Slicing (Substrings)

Extracting a portion of a string is called slicing. In Python, slicing uses square brackets with up to three parameters separated by colons: string[start:end:step].

  • start: The starting index (inclusive). Defaults to index 0 if omitted.
  • end: The stopping index (exclusive—stops 1 position before). Defaults to the end of the string if omitted.
  • step: The increment value (how many characters to step forward each time). Defaults to 1.
strings.py
Python 
phrase = "Python Programming"

# Slice from index 0 up to (but not including) index 6
print(phrase[0:6]) # "Python"

# Omitting start defaults to 0
print(phrase[:6])  # "Python"
print(phrase[0:6]) # Equivalent to above
# ** If it makes more sense to explicitly state the start index of 0, do it!

# Omitting end defaults to the end
print(phrase[7:])  # "Programming"
print(phrase[7:len(phrase)]) # Equivalent to above
# ** If it makes more sense to explicitly state the end index of len(str), do it!

Negative Indexes in Slicing

Python allows you to count backward from the end of a string using negative indexes. Index -1 represents the very last character, -2 is the second-to-last character, and so on.

strings.py
Python 
word = "COMPUTER"

# Grab the last character
print(word[-1]) # "R"

# Slice from index 0 up to the 3rd character from the end
print(word[:-3]) # "COMPU"

# Slice the last 4 characters
print(word[-4:]) # "UTER"

Python-Specific Feature Warning:

Negative indexing is a unique convenience feature built into Python! Most other major programming languages (including Java, C++, and C#) do not support negative indexes. If you try using a negative index in Java (AP CSA), your program will crash with an StringIndexOutOfBoundsException error. Use this trick in Python, but remember it won't cross over to other languages!

The step Parameter

The optional third parameter, step, controls how Python skips through characters during a slice. By default, step is 1 (reading every character in sequence).

If you change step to 2, Python skips every other character. Setting step to -1 reverses the direction and reads the string backward!

strings.py
Python 
text = "0123456789"

# Extract every 2nd character (step = 2)
print(text[::2]) # "02468"

# Extract every 3rd character from index 1 to 8
print(text[1:8:3]) # "147"

# Python Shortcut: Reverse a string using a step of -1
greeting = "Hello"
print(greeting[::-1]) # "olleH"

Optional: String Interpolation with f-Strings

Python 3.6 introduced f-strings (Formatted String Literals), a cleaner way to inject variables and expressions directly into text strings.

To declare an f-string, prefix the opening quotation mark with the letter f. You can then place variables or python expressions directly inside curly braces {...}.

strings.py
Python 
name = "Alex"
age = 16
gpa = 3.85

# Traditional Explicit Casting + Concatenation
print("Student " + name + " (Age " + str(age) + ") has a GPA of " + str(gpa))

# Modern f-String Interpolation (Automatic Type Casting)
print(f"Student {name} (Age {age}) has a GPA of {gpa}")

# You can even evaluate math or call methods directly inside braces
print(f"Next year, {name.upper()} will be {age + 1} years old.")

A Warning for Beginners:

While f-strings perform automatic type casting behind the scenes, you must still understand explicit type casting (str()) and basic string concatenation (+). Standard exams (including AP CSP and CSA pseudocode) test your understanding of explicit data types and manual concatenation. Stick to explicit casting and + concatenation until you are completely comfortable managing variable types, then feel free to adopt f-strings for faster project development!
