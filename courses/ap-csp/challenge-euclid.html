Weekly Challenge: Orbital Resonance — Euclidean Harmonic Validator

Apply the ancient Euclidean subtraction algorithm to calculate Greatest Common Divisors and prevent harmonic feedback between satellite engine thrusters.

Introduction

When two autonomous space probes execute formation flying maneuvers, their thruster pulse frequencies ($num1$ and $num2$) must be coprime (having a Greatest Common Divisor of 1). If two frequencies share a common factor greater than 1, harmonic resonance can build up, causing severe structural vibrations across both spacecraft.

To verify frequency safety, flight computers execute the Euclidean Algorithm using iterative subtraction. In a subtraction equation of the form Minuend - Subtrahend = Difference:

  1. Always place the larger number as the minuend and the smaller number as the subtrahend.
  2. Subtract the subtrahend from the minuend to calculate the difference.
  3. For the next iteration, take the previous subtrahend and difference as your new pair of numbers (placing the larger of the two first).
  4. Repeat this process until the subtraction yields a difference of 0.
  5. The subtrahend that produced a difference of 0 is the Greatest Common Divisor (GCD). If the GCD is 1, the integers are COPRIME. Otherwise, they are NOT COPRIME.

Program Requirements

Strict Naming & Coding Specifications:

  • File Naming Rule: Name your Python file euclid_lastname.py where lastname is replaced by your official last name (e.g., euclid_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named euclid(num1, num2) that accepts two integer parameters: num1 and num2.
  • Output Specifications:
    • Your function must return a multi-line string where each step of the algorithm is formatted as Minuend-Subtrahend=Difference on a new line.
    • The final line of the returned string must state either "COPRIME" (if GCD = 1) or "NOT COPRIME" (if GCD > 1).
