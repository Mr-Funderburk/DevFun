Variables & Data Types

What are Variables?

A variable is an abstract storage location paired with a descriptive symbolic name that contains a value. Think of a variable as a labeled box in memory where you can store data to reference and manipulate later.

The syntax for a Python variable is: name = value

data-types.py
Python 
# Declaring variables in Python: [variable_name] = [value]
age = 15
myAge = 21
HerAge = 33
the_dogs_age = 87

Naming Rules

While variables can be named almost anything, there are a few "hard" rules that you have to follow. Not following these rule will cause your program to error.

Hard Rules

  • Can only contain letters (A-Z, a-z), numbers (0-9), and underscores (_).
  • Cannot start with a number (e.g., 1st_name is invalid).
  • No spaces allowed anywhere in the variable name.
  • Case-sensitive (age and Age are two different variables).
  • Cannot use Python's Reserved Words. (see the table below)

After the "hard" rules, we have some "soft" rules (or suggestions). There are a few that will be enforced in this class, but many more in Python's PEP 8 Style Guide.

Soft Rules

  • Short, descriptive names. You should be able to tell what data the variable will hold just by the name.
  • Snake Case. This is the preferred method for Python, where every word is lowercase and separated by an underscore. Example: my_awesome_variable
  • Avoid single-letter variables (some exceptions will apply). Variables like a or b are not descriptive of the data they will contain.

Python Reserved Words

These words are keywords in the Python language with special function. These words cannot be used as variable name.

False def if raise None del import return True elif in try and else is while as except lambda with assert finally nonlocal yield break for not class from or continue global pass

Data Types

A data type is a classification that defines the kind of value a variable can hold.

ELI5

A data type is a label that tells a computer what kind of inforation it is dealing with, ensureing the data is stored and processed correctly. Think of it like sorting real-world objects: You would handle sharp objects differently than building blocks.

Under the hood, this classification is crucial because it dictates how much memory to set aside for the data and what operations are allowed.

Python's variables are dynamically typed. Which means, Python doesn't require you to expressly state what type of data your variable holds. It will look at the data it is given and figure it out for you. However, many other languages require you to be specific. So it is important to build habits now: like taking into consideration what data the variable will hold.

Python uses four basic built-in types: Integers - int, Floating-Points - float, Booleans - bool, and Strings - str
