Weekly Challenge: Tactical Radio Dispatch — Phonetic Telemetry Relay

Build a low-bandwidth message encoder using dictionary lookups, string tokenization, and character formatting.

Introduction

During arctic scientific expeditions, voice radio communications often suffer from high atmospheric interference and signal degradation. To ensure critical dispatch coordinates and messages are transmitted without error, radio operators rely on standardized phonetic spelling alphabets. By replacing individual letters with distinct code words (such as Alpha for A or Bravo for B), operators eliminate ambiguity across noisy radio channels.

Your task is to build an automated Tactical Radio Encoder for the dispatch terminal. Your software must parse plain-text text messages, translate every letter into its official phonetic code word in uppercase, hyphenate the code words within each word, and preserve word boundaries with spaces.

Program Requirements

Strict Specifications & Rules:

  • File Naming Rule: Name your Python file phonetic_lastname.py where lastname is replaced by your official last name (e.g., phonetic_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named phonetic(msg) that takes a single parameter msg (a plain-text string).
  • Encoding Specifications:
    • All code words in the return string must be in ALL CAPS.
    • Phonetic words within the same plain-text word must be separated by a hyphen (-).
    • Spaces between words in the original message must be preserved as spaces in the encoded string.
    • No trailing hyphens should exist at the end of words or at the end of the final returned string.
    • Your function should handle upper and lowercase input seamlessly (e.g., both 'a' and 'A' map to "ALPHA").
    • You may assume inputs contain only English letters and spaces (no numbers or punctuation).
