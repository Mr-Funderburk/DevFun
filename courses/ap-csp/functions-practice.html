Guided Practice: Functions

Overview

In this guided practice, you will write a series of Python functions that focus on boolean evaluations, arithmetic logic, and string manipulation. Create a single Python file named functions_practice_lastname.py (replacing lastname with your actual last name in lowercase) and implement all twelve functions below.

CRITICAL REQUIREMENT:

Every function in this exercise must RETURN a value using the return keyword. Do NOT use print() inside your function definitions unless you are testing your function calls outside of them.

Function Practice Problems

1. can_alarm_ring(is_weekend, is_holiday)

We want to sleep in! The alarm clock should NOT ring if it is the weekend or if we are on holiday. Create a function that accepts two boolean parameters, is_weekend and is_holiday, and returns True if the alarm rings, or False if it should stay silent.

Function Call Expected Return Value
can_alarm_ring(False, False) True
can_alarm_ring(True, False) False
can_alarm_ring(False, True) False

2. cat_and_dog_silent(cat_meowing, dog_barking)

We have a cat and a dog. We are at peace if both pets are silent, or if both pets are making noise at the same time. Create a function that accepts two boolean parameters, cat_meowing and dog_barking, and returns True if we are at peace, or False otherwise.

Function Call Expected Return Value
cat_and_dog_silent(False, False) True
cat_and_dog_silent(True, True) True
cat_and_dog_silent(True, False) False

3. quadruple_even(a, b)

Given two integer parameters, a and b, return their sum. However, if both integers are even numbers (divisible by 2), return four times their sum.

Function Call Expected Return Value
quadruple_even(3, 5) 8
quadruple_even(2, 4) 24
quadruple_even(2, 3) 5

4. diff_fifty(n)

Given an integer parameter n, return the absolute difference between n and 50. Exception: If n is strictly greater than 50, return triple the absolute difference.

Function Call Expected Return Value
diff_fifty(40) 10
diff_fifty(50) 0
diff_fifty(60) 30

5. stadium_lights(game_on, hour)

The outdoor stadium lights should turn on if a game is currently happening (game_on is True) AND the current time in hours (0 through 23) is before 8 AM (hour < 8) or after 6 PM (hour > 18). Return True if the lights should be turned on, and False otherwise.

Function Call Expected Return Value
stadium_lights(True, 20) True
stadium_lights(True, 12) False
stadium_lights(False, 22) False

6. sum_or_twenty(a, b)

Given two integer parameters, a and b, return True if either integer is 20, or if their sum equals 20. Return False otherwise.

Function Call Expected Return Value
sum_or_twenty(20, 5) True
sum_or_twenty(12, 8) True
sum_or_twenty(10, 5) False

7. near_target(n, target)

Given an integer n and a target value target, return True if n is within 5 units (inclusive) of target in either direction. (Hint: Use the built-in abs() function to compute absolute difference).

Function Call Expected Return Value
near_target(98, 100) True
near_target(106, 100) False
near_target(45, 50) True

8. opposite_signs(a, b, both_negative)

Given two numbers a and b, return True if one number is positive and the other is negative. However, if the boolean parameter both_negative is True, return True only if both a and b are negative.

Function Call Expected Return Value
opposite_signs(5, -3, False) True
opposite_signs(-2, -4, True) True
opposite_signs(-2, -4, False) False

9. add_super(text)

Given a string text, return a new string where "super " is added to the beginning. However, if the string already begins with "super ", return the original string unchanged.

Function Call Expected Return Value
add_super("hero") "super hero"
add_super("super star") "super star"
add_super("fast") "super fast"

10. drop_character(text, idx)

Given a non-empty string text and a valid zero-based integer index idx, return a new string where the character at position idx has been removed using string slicing.

Function Call Expected Return Value
drop_character("python", 2) "pyhon"
drop_character("robot", 0) "obot"
drop_character("code", 3) "cod"

11. swap_ends(text)

Given a string text, return a new string where the first and last characters have exchanged places. If the string length is 1 or less, return the string unchanged.

Function Call Expected Return Value
swap_ends("apple") "eppla"
swap_ends("hi") "ih"
swap_ends("z") "z"

12. repeat_prefix(text)

Given a string text, take the first 2 characters of the string and return a new string that repeats those 2 characters 4 times. If the input string length is less than 2, repeat whatever characters are present 4 times.

Function Call Expected Return Value
repeat_prefix("Python") "PyPyPyPy"
repeat_prefix("A") "AAAA"
repeat_prefix("CS") "CSCSCSCS"
