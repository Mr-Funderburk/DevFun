User Input in Python

A critical aspect of programming is the ability to take information from a user and manipulate it. Python provides a robust mechanism to interact dynamically, but we must understand how it interprets the data it receives.

Python offers a simple framework for text-based user input using the input([prompt]) function. The syntax is crucial: the optional prompt inside the parentheses is the message displayed to the user. The dynamic sequence is as follows:

  • Display Prompt: The program outputs the prompt text (e.g., a question).
  • Halt Execution: The Python interpreter stops and waits.
  • Wait for Input: The program pauses until the user types text and presses [Enter].
  • Resume: The function receives the typed text and the program continues.

Printing Direct Input

The simplest way to verify the input() mechanism is to immediately print the result. Try running the following code block in your Python editor. Note how the prompt appears, and the output is generated only after you press [Enter].

Python 
print(input("What is your name? "))

Storing Input: Using Variables

Simply printing or testing the input is useful for diagnostic checks, but in a functional application, we need to keep the data for later or manipulate it further. We can set a variable to the value of the input, just as we would assign any other variable in Python. Consider the comprehensive example below:

user-input.py
Python 
# 1. Take raw input (received as a string)
age = input("What is your age? ")

# 2. Manipulate the data (requires casting to int)
age_in_ten = age + 10

# 3. Output the final result
print(age_in_ten)

Unfortunately, this code crashes. Why do you think that is? What is the error?

How Input is Treated

Python treats all user input as a string. This is important. In the above example, we attempt to add ten (an integer) to the user's age (since it's user input, it's a string). This is like asking someone what 2 plus 'fish' is. It just doesn't make sense. So how do we make it work?

Type Casting

Type casting in Python is the process of converting a value from one data type to another.

There are two types of type casting in Python:

  • Implicit Type Casting: Python automatically converts a lower-capability type to a higher-capability type (e.g., int to float) to prevent data loss during operations. This happens without any code from the developer and is always safe.
  • Explicit Type Casting: The developer manually converts a value using built-in functions like int(), float(), str(), or bool(). This is required when Python cannot automatically determine the correct type or when converting to a lower-capability type (e.g., float to int), which may result in data loss.

So to make our previous example work, we need to convert (or cast) the user input to an integer. Update line 5 to be age_in_ten = int(age) + 10. This will tell Python that we want to take the value of age (which is a string right now) and convert (or cast) the value to an integer. Now we can run our code and as long as the user inputs a valid integer, the code runs perfectly.

What happens when the user does not entire an integer though? What if they input 'fish'? Or even a float like 2.2? This is a concern that developers have to be aware of. We will cover more of this when we start talking about validation.
