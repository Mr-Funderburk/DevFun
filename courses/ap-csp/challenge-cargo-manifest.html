Weekly Challenge: Deep Space Logistics — Cargo Manifest Evaluator

Parse arbitrary-length manifest streams, match cargo keywords against weight tables, and validate spacecraft payload thresholds.

Introduction

As Automated Cargo Specialist for NASA's Artemis Lunar Logistics Division, you oversee automated supply launches to the Lunar Gateway Station. Spacecraft payload limits are strictly governed by orbital mechanics: exceeding maximum mass capacity prevents orbit insertion, while launching an empty or unrecognizable payload wastes multi-million-dollar rocket boosters.

Before launching a supply rocket, your automated guidance system receives a single telemetry manifest string. Your program must parse the mission header and maximum capacity threshold, process a comma-separated stream of item keywords of unknown length, calculate total cargo mass using official supply weights, and declare whether the payload is approved or overweight.

Official Cargo Weight Reference Table

Your software must cross-reference item keywords against the official supply mass values (in kg) below:

Program Requirements

Strict Specifications & Rules:

  • File Naming Rule: Name your Python file cargo_lastname.py where lastname is replaced by your official last name (e.g., cargo_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named evaluate_cargo(manifest_data) that accepts one parameter manifest_data.
  • Input String Format: manifest_data is a single pipe-delimited (|) string formatted as:
    "MissionName|MaxCapacity|Item1, Item2, Item3, ..."
  • Parsing & Processing Specifications:
    • The list of item keywords is of unknown length (may contain 0, 1, or many items).
    • Item keywords must be case-insensitive (e.g., 'oxygen', 'Oxygen', and 'OXYGEN' all equal 15 kg).
    • Surrounding whitespace around item names or mission headers must be trimmed cleanly.
    • Unrecognized keywords (e.g., 'JUNK', 'DEBRIS') have a mass of 0 kg and should be ignored.
    • Duplicate item keywords in a manifest must each be counted toward total mass.
  • Return Output Requirements: Your function must return one of the exact formatted string values:
    • "<MissionName>, Empty Manifest!" (if total valid cargo weight is 0 kg)
    • "<MissionName>, Manifest Approved: <total_weight> kg" (if total valid cargo weight ≤ MaxCapacity)
    • "<MissionName>, Manifest Overweight: <total_weight> kg" (if total valid cargo weight > MaxCapacity)

Sample Test Cases

Verify your solution against the expected output formatting below:

Input Manifest String (manifest_data) Expected Return String Calculation & Logic Breakdown
"Artemis-1|60|OXYGEN, WATER, RATIONS, FUEL" "Artemis-1, Manifest Approved: 55 kg" 15 + 10 + 5 + 25 = 55 kg. (55 ≤ 60) → Approved.
"Ares-2|55|OXYGEN, WATER, RATIONS, FUEL" "Ares-2, Manifest Approved: 55 kg" 15 + 10 + 5 + 25 = 55 kg. (55 ≤ 55 Exact Boundary) → Approved.
"Gateway-1|54|OXYGEN, WATER, RATIONS, FUEL" "Gateway-1, Manifest Overweight: 55 kg" 15 + 10 + 5 + 25 = 55 kg. (55 > 54) → Overweight.
"Rover-X|100|JUNK, TRASH, SCRAP" "Rover-X, Empty Manifest!" No valid keywords match weight reference table (0 kg).
