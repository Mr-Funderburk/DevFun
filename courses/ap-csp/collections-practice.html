Guided Practice: Collections

Overview

In this guided practice, you will build Python functions that manipulate lists, tuples, dictionaries, and sets using indexing, membership checks (in), collection functions (len()), and built-in methods. Create a single Python file named collections_practice_lastname.py (replace lastname with your actual last name in lowercase) and implement all functions below.

GUIDED RULES:

1. Every function must RETURN a value. Do NOT use print() inside function bodies.
2. Do NOT use loops (for or while) in this practice—rely strictly on collection indexing, membership testing, set math, and built-in methods.

Function Practice Problems

1. add_unique_item(cart, item)

Write a function that accepts a list parameter cart and a string parameter item. If item is not already present in cart, append it to the list. Return the updated list cart regardless of whether an item was added.

collections-practice.py
Python 
# Example Execution
items = ["apple", "banana"]
result1 = add_unique_item(items, "cherry")
# Returns: ["apple", "banana", "cherry"]

result2 = add_unique_item(result1, "apple")
# Returns: ["apple", "banana", "cherry"] (No duplicate added)

2. get_coordinate_distance(point_a, point_b)

Write a function that accepts two tuples, point_a and point_b, where each tuple contains two numbers representing 2D coordinates (x, y). Return the sum of the horizontal distance between the x-values and the vertical distance between the y-values. (Hint: Use abs() to calculate distance differences).

collections-practice.py
Python 
# Example Execution
p1 = (2, 5)
p2 = (6, 1)

dist = get_coordinate_distance(p1, p2)

3. get_student_score(gradebook, student_name)

Write a function accepting a dictionary parameter gradebook (mapping student names to integer scores) and a string parameter student_name. If the student exists in the gradebook, return their numeric score. If the student name is not in the dictionary, return the string "Not Found".

collections-practice.py
Python 
# Example Execution
scores = {"Alice": 95, "Bob": 88, "Charlie": 72}

print(get_student_score(scores, "Bob"))      # Returns: 88
print(get_student_score(scores, "David"))    # Returns: "Not Found"

4. update_inventory_stock(inventory, item_name, quantity)

Write a function accepting a dictionary inventory, a string item_name, and an integer quantity. If item_name already exists in the dictionary, add quantity to its current stock value. If it does not exist, add the new item key with its value set to quantity. Return the modified inventory dictionary.

collections-practice.py
Python 
# Example Execution
store_stock = {"pencils": 10, "erasers": 5}

# Updating an existing item
update_inventory_stock(store_stock, "pencils", 15)
# Returns: {"pencils": 25, "erasers": 5}

# Adding a brand-new item
update_inventory_stock(store_stock, "pens", 8)
# Returns: {"pencils": 25, "erasers": 5, "pens": 8}

5. swap_list_extremes(items)

Write a function accepting a list parameter items. If the list contains fewer than 2 items, return the list unchanged. If it contains 2 or more items, swap the position of the first item (index 0) and the last item (index -1 or len(items) - 1) and return the modified list.

collections-practice.py
Python 
# Example Execution
numbers = [10, 20, 30, 40]
result = swap_list_extremes(numbers)
# Returns: [40, 20, 30, 10]

single_item = [99]
print(swap_list_extremes(single_item))
# Returns: [99]
