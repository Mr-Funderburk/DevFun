CSS States & Display

Bringing Web Pages to Life with States

So far, all our styles have been static. But web pages are interactive! Users hover over buttons, click links, and navigate through forms using their keyboard.

In CSS, a pseudo-class is a keyword added to a selector that specifies a special state of the targeted element. Pseudo-classes begin with a colon (:) and allow you to apply styles dynamically based on user actions.

Link States: The LVHA Rule

Hyperlinks (<a> tags) have four primary interaction states. To ensure your styles work correctly without getting overridden by cascading conflicts, always define link states in the **LVHA** order:

  1. :link — A normal, unvisited link that the user has not clicked yet.
  2. :visited — A link that the user has already visited in their current browser history.
  3. :hover — Triggers when the user moves their mouse cursor over the link.
  4. :active — Triggers at the exact moment the link is being clicked down.
link-states.css
CSS 
/* 1. Unvisited Link */
a:link {
    color: #38bdf8;
    text-decoration: none;
}

/* 2. Visited Link */
a:visited {
    color: #a855f7;
}

/* 3. Mouse Hover */
a:hover {
    color: #facc15;
    text-decoration: underline;
}

/* 4. Active Click */
a:active {
    color: #ef4444;
}

Memory Trick: Lord Vader's Handle's Awesome (LVHA)

If you write a:hover before a:visited, the visited style will override the hover effect whenever a user visits that link! Stick strictly to :link → :visited → :hover → :active.

Try Me!
The :link pseudo-class styles a link that has not been visited yet. This is the link's default state.

Hover & Focus Beyond Links

Pseudo-classes aren't just for hyperlinks! You can apply :hover and :focus to buttons, cards, images, and form inputs to create responsive feedback.

Keyboard Accessibility: The :focus State

When users press the Tab key to navigate a web page, the browser moves focus from one interactive element to another. The :focus pseudo-class styles the active element receiving keyboard input.

interactive-elements.css
CSS 
/* Hover state on article cards */
.card {
    background-color: #1e293b;
    border: 2px solid #334155;
}

.card:hover {
    border-color: #38bdf8;
    background-color: #0f172a;
}

/* Focus state for keyboard accessibility */
button:focus,
a:focus {
    outline: 3px solid #facc15;
    outline-offset: 2px;
}

The CSS display Property

Every HTML element has a default layout behavior that determines how it sits alongside other elements on the screen. The display property allows you to change an element's structural rendering mode.

Core CSS Display Options
Display Value Flow Behavior Width / Height & Margins Default HTML Examples
block Starts on a new line and stretches to fill 100% of available width. Respects custom width, height, padding, and top/bottom margin. <div>, <p>, <h1>-<h6>, <article>
inline Sits side-by-side on the same line without breaking to a new line. Ignores custom width and height! Ignores top/bottom margin. <span>, <a>, <strong>, <em>
inline-block Sits side-by-side on the same line like inline. Respects custom width, height, padding, and margin like block! <button>, <input>, <img>
none Completely removes the element from the page layout. Hides content and frees up its screen space completely. Used for dynamic popups, dropdowns, and mobile menus.

Why `inline-block` is Essential for Buttons and Links

By default, <a> tags are display: inline, which means browsers ignore top and bottom padding/margins! Converting navigation links to display: inline-block allows you to add custom padding, turning small text links into large, clickable navigation buttons.

Putting It Together

In your web-1/learning/ folder, create a new file named states-and-display.html and link it to a stylesheet named states.css.

states-and-display.html
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Interactive States &amp; Display Modes</title>
    <link rel="stylesheet" href="states.css">
</head>
<body>
    <header>
        <h1>Interactive Navigation</h1>
        <nav>
            <a href="index.html" class="nav-link">Home</a>
            <a href="fan-page.html" class="nav-link">Fan Page</a>
            <a href="box-model.html" class="nav-link">Box Model</a>
        </nav>
    </header>

    <main>
        <section class="card-grid">
            <article class="interactive-card">
                <h2>Interactive Card One</h2>
                <p>Hover or focus on this box to see dynamic background feedback.</p>
                <button class="btn btn-action">Click Me</button>
            </article>

            <article class="interactive-card">
                <h2>Interactive Card Two</h2>
                <p>Uses display inline-block buttons with custom spacing.</p>
                <button class="btn btn-action">Explore</button>
            </article>
        </section>
    </main>
</body>
</html>

Now write the corresponding CSS in states.css using pseudo-classes and custom display modes:

states.css
CSS 
/* Universal Reset */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    background-color: #0b1020;
    color: #e2e8f0;
    font-family: sans-serif;
    padding: 24px;
}

/* 1. Navigation Links using inline-block */
.nav-link {
    display: inline-block; /* Allows vertical padding & height */
    padding: 10px 18px;
    margin-right: 8px;
    background-color: #1e293b;
    color: #38bdf8;
    text-decoration: none;
    border-radius: 6px;
    border: 2px solid transparent;
}

/* Link States (LVHA) */
.nav-link:visited {
    color: #cbd5e1;
}

.nav-link:hover {
    background-color: #38bdf8;
    color: #0f172a;
}

.nav-link:active {
    background-color: #0284c7;
    color: #ffffff;
}

.nav-link:focus {
    outline: 2px solid #facc15;
    outline-offset: 3px;
}

/* 2. Interactive Block Cards */
.interactive-card {
    display: block;
    background-color: #151d32;
    border: 2px solid #334155;
    padding: 24px;
    margin-top: 20px;
    border-radius: 8px;
}

/* Hover feedback on non-link containers */
.interactive-card:hover {
    border-color: #4ade80;
    background-color: #192642;
}

/* 3. Button Component */
.btn {
    display: inline-block;
    padding: 10px 20px;
    margin-top: 14px;
    font-weight: bold;
    border: none;
    border-radius: 4px;
    cursor: pointer;
}

.btn-action {
    background-color: #4ade80;
    color: #052e16;
}

.btn-action:hover {
    background-color: #22c55e;
}

.btn-action:active {
    background-color: #15803d;
    color: #ffffff;
}

Practice Exercise & Challenges

Test your knowledge of interactive pseudo-classes and display behavior with these hands-on challenges:

  1. Build an Interactive Navigation Bar: Take your navigation links inside header and style them so they sit side-by-side using display: inline-block. Add distinct :hover background fills and :active color changes when clicked!
  2. The Keyboard Accessibility Check: Put your mouse away! Press Tab on your keyboard to navigate through your page. Write a :focus selector in CSS that highlights active links with a high-contrast yellow outline.
  3. Create a "Hidden Alert" Toggle Test: Add a paragraph with class .secret-banner that has display: none; by default. Create a rule so when you hover over its parent container, the paragraph changes to display: block;!
  4. Card Accent Shifting: Add a left border (e.g., border-left: 6px solid #334155;) to your article cards. Write a :hover rule that shifts that border color to bright green (#4ade80) whenever the mouse floats over the card.
