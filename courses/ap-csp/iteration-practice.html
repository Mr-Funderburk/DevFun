Guided Practice: Iteration

Work through these step-by-step coding challenges to master for-each loops, index ranges, while loops, and control flow.

Exercise 1: For-Each Loop (Accumulator Pattern)

Goal: Iterate through a list of exam scores, count how many scores are passing (70 or higher), and calculate the total score of all passing grades.

practice1_starter.py
Python 
scores = [85, 62, 91, 74, 55, 88, 70, 48]

passing_count = 0
passing_total = 0

# TODO: Write a for-each loop to process each score
# 1. Check if score >= 70
# 2. Increment passing_count by 1
# 3. Add score to passing_total

print("Passing students:", passing_count)
print("Passing sum:", passing_total)
View Solution & Explanation
practice1_solution.py
Python 
scores = [85, 62, 91, 74, 55, 88, 70, 48]

passing_count = 0
passing_total = 0

for score in scores:
    if score >= 70:
        passing_count += 1
        passing_total += score

print("Passing students:", passing_count)  # Output: 5
print("Passing sum:", passing_total)       # Output: 408

Exercise 2: Standard For Loop & range()

Goal: Print a numbered roster for a list of runners, but only print runners at even index positions (0, 2, 4, ...).

practice2_starter.py
Python 
runners = ["Alice", "Bob", "Charlie", "Diana", "Ethan", "Fiona"]

# TODO: Write a for loop using range() with start, stop, and step parameters
# Print each runner in the format: "Lane [i]: [Runner Name]"
View Solution & Explanation
practice2_solution.py
Python 
runners = ["Alice", "Bob", "Charlie", "Diana", "Ethan", "Fiona"]

# range(start=0, stop=len(runners), step=2)
for i in range(0, len(runners), 2):
    print(f"Lane {i}: {runners[i]}")

# Expected Output:
# Lane 0: Alice
# Lane 2: Charlie
# Lane 4: Ethan

Exercise 3: While Loop Countdown (Preventing Infinite Loops)

Goal: Simulate a fuel launch countdown starting at 10. Decrease the fuel level by 2 each step. Stop immediately when fuel drops to 0 or below and print "Liftoff!".

practice3_starter.py
Python 
fuel = 10

# TODO: Write a while loop condition
# 1. Print current fuel level
# 2. Update fuel variable to avoid an infinite loop

print("Liftoff!")
View Solution & Explanation
practice3_solution.py
Python 
fuel = 10

while fuel > 0:
    print(f"Fuel level: {fuel}")
    fuel -= 2  # Decrements fuel state to terminate loop eventually

print("Liftoff!")

# Expected Output:
# Fuel level: 10
# Fuel level: 8
# Fuel level: 6
# Fuel level: 4
# Fuel level: 2
# Liftoff!

Exercise 4: Loop Control (break & continue)

Goal: Process a sensor data stream list containing numerical values:

  • If a reading is negative, skip it using continue (invalid sensor noise).
  • If a reading equals -999, stop processing entirely using break (emergency shutdown).
  • Otherwise, print "Valid sensor reading: [value]".
practice4_starter.py
Python 
readings = [23, -5, 18, 30, -999, 12, 45]

for data in readings:
    # TODO: Handle -999 emergency code with break
    
    # TODO: Handle invalid negative noise with continue
    
    print("Valid sensor reading:", data)
View Solution & Explanation
practice4_solution.py
Python 
readings = [23, -5, 18, 30, -999, 12, 45]

for data in readings:
    if data == -999:
        print("Emergency stop signal detected!")
        break
    if data < 0:
        continue  # Skips negative numbers like -5
    
    print("Valid sensor reading:", data)

# Expected Output:
# Valid sensor reading: 23
# Valid sensor reading: 18
# Valid sensor reading: 30
# Emergency stop signal detected!
