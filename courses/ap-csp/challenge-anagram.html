Weekly Challenge: Quantum Encryption — Anagram Signal Validator

Parse delimited transmission pairs, normalize character streams, and verify scrambled signal integrity using boolean logic.

Introduction

During deep-space research missions, encrypted telemetry feeds transmit sensitive mission data in paired phrases. To verify signal integrity and prevent data corruption caused by cosmic radiation, the receiving station relies on a Quantum Anagram Handshake.

An anagram is a word or phrase formed by rearranging the letters of a different word or phrase, using all the original letters exactly once. If the incoming transmission pair is a valid anagram pair, the function confirms signal integrity with a boolean True. If any characters are missing, duplicated, or corrupted, it flags a signal abort with False.

Your task is to build an automated Anagram Signal Validator. Your program will receive a single pipe-delimited telemetry string, clean and normalize both phrases, evaluate if they are exact anagrams, and return the boolean result.

Program Requirements

Strict Specifications & Rules:

  • File Naming Rule: Name your Python file anagram_lastname.py where lastname is replaced by your official last name (e.g., anagram_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named check_anagram(signal_data) that accepts one parameter signal_data.
  • Input String Format: signal_data is a single pipe-delimited (|) string containing two words or phrases:
    "StringOne|StringTwo"
  • Validation Specifications:
    • Case-Insensitive: Letter comparisons must ignore upper/lowercase differences (e.g., 'Listen' and 'Silent' match).
    • Cleanly trim leading/trailing whitespace surrounding the strings before processing.
  • Return Output Requirements: Your function must return a boolean value:
    • True (if the two strings are valid anagrams)
    • False (if the two strings are NOT valid anagrams)

Sample Test Cases

Test Cases Table
Input Telemetry String (signal_data) Expected Return Value Reasoning
"Listen|Silent" True Both contain identical letters: e, i, l, n, s, t.
"Mike|Mike" False Two strings that are the same are not anagrams.
"STOP|POTS" True Both contain identical letters: s, t, o, p.
"Hello|World" False Letter compositions do not match.

Test Your Code Locally

Copy and paste the test harness below into the bottom of your Python file to run automated checks against the sample inputs:

if __name__ == "__main__":
    sample_tests = [
        ("Listen|Silent", True),
        ("Mike|Mike", False),
        ("STOP|POTS", True),
        ("Hello|World", False)
    ]

    print("\n--- RUNNING LOCAL TESTS ---")
    passed = 0
    for sample_input, expected in sample_tests:
        actual = check_anagram(sample_input)
        if actual == expected:
            print(f"PASS: '{sample_input}'")
            passed += 1
        else:
            print(f"FAIL: '{sample_input}'\n   Expected: {expected}\n   Got:      {actual}\n")
            
    print(f"Result: {passed}/{len(sample_tests)} sample tests passed.\n")
