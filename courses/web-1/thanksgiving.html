Project: Thanksgiving Single-Page Showcase

Project Overview

In this project, you will design and build a responsive, single-page website themed around Thanksgiving. This project synthesizes key layout and positioning skills: custom font styling, CSS Grid/Flexbox container alignment, absolute element positioning, and in-page anchor smooth scrolling.

Two Recommended Ideas for Extra Sections

In addition to History and Traditions, your page must feature two additional content sections. Here are two section concepts tailored for custom styling:

  • 1. The Thanksgiving Feast & Recipe Corner: A grid of favorite dishes (Turkey, Stuffing, Pumpkin Pie) featuring ingredient tables, custom image cards, and absolute-positioned "Family Favorite" badges.
  • 2. The Gratitude Board: A collection of styled note cards or quotes displaying things, people, or events you are thankful for this year, formatted using Flexbox or Grid.

Core Required Web Page Sections

Your single-page layout must contain a sticky header navigation bar that smooth-scrolls to four distinct section IDs:

  1. History of Thanksgiving: Background on the origins of the holiday, historical details, and at least one absolute link to an external source (e.g., History Channel or encyclopedia) opening in a new tab.
  2. Family or General Traditions: Details on annual activities, parades, touch football games, or morning prep routines.
  3. The Thanksgiving Feast (Section Idea 1): Styled grid or list layout showcasing signature holiday foods, recipes, or menu cards.
  4. The Gratitude Board (Section Idea 2): Styled card wall highlighting things you are thankful for.

Grading Benchmark & Requirements

Thanksgiving Project Evaluation Rubric
Requirement Baseline ("B" Grade) Excellence ("A" Grade)
Page Structure Single-page HTML document containing all 4 required sections with valid semantic tags. Advanced semantic markup with clean section IDs and smooth intra-page scrolling (html { scroll-behavior: smooth; }).
Layout Systems Uses standard Flexbox or Grid for at least 2 sections. Combines CSS Grid for multi-column bento/card sections and Flexbox for sticky navigation and footer elements.
Typography & Fonts Custom font stack applied via standard CSS system fonts. Imports and applies custom Google Fonts (e.g., Playfair Display for headers, Inter for body text).
CSS Positioning Uses basic position: sticky or position: relative. Implements at least one floating badge using position: absolute; anchored relative to its parent container (position: relative;).
Hyperlinks Internal anchor links in navigation bar. Internal anchor links plus at least one external absolute link with target="_blank" and rel="noopener noreferrer".

Technical Code Snippet Examples

1. In-Page Anchor Links (Internal Hyperlinks)

anchor-links.html
HTML 
<!-- Navigation Bar Anchor Links -->
<nav>
    <a href="#history">History</a>
    <a href="#traditions">Traditions</a>
    <a href="#feast">The Feast</a>
    <a href="#gratitude">Gratitude</a>
</nav>

<!-- Target Section -->
<section id="feast">
    <h2>The Thanksgiving Feast</h2>
</section>

2. Absolute Positioning Overlay Badge

absolute-badge.css
CSS 
/* Parent container must be relative */
.food-card {
    position: relative;
    background-color: #271c19;
    border-radius: 12px;
    padding: 20px;
}

/* Floating child badge placed with absolute positioning */
.badge-favorite {
    position: absolute;
    top: -10px;
    right: 16px;
    background-color: #ea580c;
    color: #ffffff;
    font-size: 0.75rem;
    font-weight: bold;
    padding: 4px 10px;
    border-radius: 20px;
}

Submission Checklist

  1. Single index.html file with functioning anchor navigation linking to all 4 required sections.
  2. External Google Font imported in the <head> and applied in css/style.css.
  3. At least one image or element styled with position: absolute; inside a position: relative; parent.
  4. At least one absolute external hyperlink opening in a new window using target="_blank".
  5. All images stored locally in an images/ folder and referenced using correct relative paths.
  6. Zip the thanksgiving-project/ directory and submit via the portal.
