Challenge: Customs Duty Auditor

Parse passenger manifests, look up tier allowances, calculate key-value item pairs, and assess duty taxes on orbital imports.

Introduction

Commercial sub-orbital flight lines carry passengers between Earth and orbital habitats. Upon re-entering Earth's airspace, all passengers must declare luxury lunar souvenirs, rare meteorites, and orbital technological artifacts brought back from space.

To keep customs processing fast and efficient, the spaceport relies on an automated guidance terminal. Different passenger ticket tiers receive different duty-free baggage allowances. Your automated software must parse a passenger declaration string, look up the passenger's duty-free allowance, total the value of declared items, and assess a 15% customs duty tax on any value exceeding their allowance.

Official Duty-Free Tier Allowances

Your program must map ticket classes to their official duty-free allowance values (in USD) below:

Ticket Class Duty-Free Allowance
VIP$500.00
BUSINESS$350.00
STANDARD$200.00
ECONOMY$100.00

Note: Unrecognized or unlisted ticket classes receive a $0.00 allowance.

Program Requirements

Strict Specifications & Rules:

  • File Naming Rule: Name your Python file customs_lastname.py where lastname is replaced by your official last name (e.g., customs_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named evaluate_customs(passenger_data) that accepts one parameter passenger_data.
  • Input String Format: passenger_data is a single pipe-delimited (|) string formatted as:
    "PassengerName|TicketClass|Item1:Price1,Item2:Price2,Item3:Price3..."
  • Parsing & Calculations:
    • The list of declared items is comma-separated and may contain 0, 1, or many Item:Price pairs.
    • Ticket class comparisons must be case-insensitive (e.g., "vip", "Vip", and "VIP" all map to $500.00).
    • Prices are floating-point values (e.g., 300 or 120.50).
    • Cleanly trim whitespace around passenger names, ticket classes, item names, and prices.
    • If total declared value is less than or equal to the allowance, duty owed is $0.00.
    • If total declared value exceeds the allowance, assess a 15% tax (0.15) ONLY on the amount *over* the allowance.
  • Return Output Requirement: Return an exact string formatted as:
    "<PassengerName> (<TicketClass>), Customs Duty Owed: $<duty_amount>"
    (Note: Preserve the original ticket class casing as given in the input string, and format the duty amount to exactly two decimal places using {duty:.2f}).

Sample Test Cases

Input Telemetry String (passenger_data) Expected Return String Mathematical Reasoning
"Eleni|VIP|MoonRock:300,ZeroGWatch:400" "Eleni (VIP), Customs Duty Owed: $30.00" Total: $700. Excess: $700 − $500 = $200. Tax: $200 × 0.15 = $30.00
"Marcus|BUSINESS|Meteorite:350" "Marcus (BUSINESS), Customs Duty Owed: $0.00" Total: $350. Allowance: $350. Exact boundary → $0.00 owed.
"Zara|STANDARD|ZeroGGlasses:150" "Zara (STANDARD), Customs Duty Owed: $0.00" Total: $150. Allowance: $200. Under allowance → $0.00 owed.
"Chen|ECONOMY|MarsDust:50,Patch:80" "Chen (ECONOMY), Customs Duty Owed: $4.50" Total: $130. Excess: $130 − $100 = $30. Tax: $30 × 0.15 = $4.50

Test Your Code Locally

Copy and paste the test harness below into the bottom of your Python file to run automated checks against the sample inputs:

challenge-customs.py
Python 
if __name__ == "__main__":
    sample_tests = [
        ("Eleni|VIP|MoonRock:300,ZeroGWatch:400", "Eleni (VIP), Customs Duty Owed: $30.00"),
        ("Marcus|BUSINESS|Meteorite:350", "Marcus (BUSINESS), Customs Duty Owed: $0.00"),
        ("Zara|STANDARD|ZeroGGlasses:150", "Zara (STANDARD), Customs Duty Owed: $0.00"),
        ("Chen|ECONOMY|MarsDust:50,Patch:80", "Chen (ECONOMY), Customs Duty Owed: $4.50")
    ]

    print("\n--- RUNNING LOCAL TESTS ---")
    passed = 0
    for sample_input, expected in sample_tests:
        actual = evaluate_customs(sample_input)
        if actual == expected:
            print(f"PASS: '{sample_input}'")
            passed += 1
        else:
            print(f"FAIL: '{sample_input}'\n   Expected: {expected}\n   Got:      {actual}\n")
            
    print(f"Result: {passed}/{len(sample_tests)} sample tests passed.\n")
