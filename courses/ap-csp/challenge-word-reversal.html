Weekly Challenge: Word Reversal — Reverse Each Word in Place

Reverse the characters in every word while keeping punctuation, contractions, capitalization, and sentence structure intact.

Introduction

Reversing an entire string from back to front is a classic introductory coding exercise. This challenge takes that concept a step further: instead of flipping the whole sentence backward, your program must reverse each individual word in place while keeping the sentence structure intact.

Your algorithm must follow three core formatting rules:

  1. Anchor Surrounding Punctuation: Standard punctuation marks and symbols must remain in their exact original positions rather than shifting to the front of a reversed word (e.g., cool! becomes looc!, and "Nevermore." becomes "Eromreven.").
  2. Reverse Contractions Together: Apostrophes inside contractions are part of the word and must travel with the letters when reversed (e.g., Don't becomes T'nod).
  3. Preserve Capitalization by Position: Uppercase and lowercase formatting stays locked to the character index, not the original letter. For example, because Cougar starts with a capital letter at index 0, its reversed form is Raguoc (with index 0 capitalized).

Program Requirements

Strict Naming & Coding Specifications:

  • File Naming Rule: Name your Python file word_reversal_lastname.py where lastname is replaced by your official last name (e.g., word_reversal_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named word_reversal(msg) that accepts one string parameter: msg.
  • Output Specifications:
    • Your function must return a string with each word reversed in its original position.
    • Preserve the original spacing and keep surrounding punctuation in its original position.
    • Include apostrophes within contractions when reversing a word, and preserve the capitalization pattern by character index.

Sample Test Cases

word_reversal("Hello world") Olleh dlrow Reverse each word in place; the first character remains uppercase by position.
word_reversal("Cool, world!") LooC, dlrow! Both punctuation marks stay at their original positions as each word reverses.
word_reversal("Don't stop.") T'nod pots. The contraction's apostrophe reverses with its word, and the period stays anchored.

Test Your Code Locally

Copy and paste the test harness below into the bottom of your Python file to run automated checks against the sample inputs:

word_reversal_lastname.py
Python 
if __name__ == "__main__":
    sample_tests = [
        ("Hello world", "Olleh dlrow"),
        ("Cool, world!", "LooC, dlrow!"),
        ("Don't stop.", "T'nod pots.")
    ]

    print("\n--- RUNNING LOCAL TESTS ---")
    passed = 0
    for msg, expected in sample_tests:
        actual = word_reversal(msg)
        if actual == expected:
            print(f"PASS for input {msg!r}")
            passed += 1
        else:
            print(f"FAIL for input {msg!r}\n--- Expected ---\n{expected}\n--- Got ---\n{actual}\n")

    print(f"Result: {passed}/{len(sample_tests)} sample tests passed.\n")
