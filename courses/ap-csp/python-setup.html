01. Big Question: Is AI Taking Software Jobs?

"Should I stop learning to code because AI might take over software jobs?"

No—you should definitely keep learning to code! Even though artificial intelligence is transforming how developers work, learning to program remains essential for understanding and shaping technology. Here is why your skills matter now more than ever:

Technology Keeps Changing

New tools appear all the time. Web developers used to write every line of raw HTML by hand, but now modern tools accelerate the build. Understanding underlying mechanics lets you use helper tools effectively instead of guessing blindly.

AI is a Co-Pilot, Not a Replacement

Think of AI like a powerful calculator. It can output code rapidly, but it requires humans to verify syntax, debug logical errors, ensure security, and decide why a product should exist.

Humans Solve Real Problems

Coding is fundamentally about human empathy, collaboration, and design. Whether building language apps or medical diagnostic software, AI lacks real-world context and human experience.

Responsible & Ethical Technology

We need thoughtful developers who evaluate bias, protect user privacy, and ensure automated systems serve society ethically and safely.

"Coding helps people make games, robots, apps, and even AI itself! Whether you want to be an engineer, a designer, or a scientist, programming trains you to think logically."

— Adapted from Anurodh Kumar, "Should I Stop Learning Programming Because AI Will Take Over Software Jobs?" (LinkedIn, 2023)

02. Development Setup Checklist

Complete these three installations to equip your workstation for the course:

Install Python 3

Download and run the official installer for your operating system. Crucial step on Windows: Check the box that says "Add python.exe to PATH" during installation.

python.org/downloads →

Choose an IDE: PyCharm

Install PyCharm

Download PyCharm, an industry standard IDE for Python development.

jetbrains.com/pycharm/ →

Disable Intellisense

For this course, you are asked to disable the intellisense option in your IDE to better learn the syntax of the language.

  1. Navigate to File > Settings (or PyCharm > Settings on macOS).
  2. Go to Editor > General > Inline Completion.
  3. Uncheck Enable local Full Line completion suggestions and any other inline completion options for your language.
  4. Alternatively, search for "Inline Completion" in the settings search bar and disable the feature entirely.

Choose an IDE: VS Code

Install Visual Studio Code

Download VS Code, our lightweight primary code editor for the year.

code.visualstudio.com →

Install the VS Code Python Extension

Open VS Code, click the Extensions icon on the left sidebar (Ctrl+Shift+X / Cmd+Shift+X), search for Python (by Microsoft), and click Install.

Disable Intellisense

For this course, you are asked to disable the intellisense option in your IDE to better learn the syntax of the language.

  1. Open the Command Palette (Ctrl+Shift+P or Cmd+Shift+P) and select Preferences: Open User Settings (JSON).
  2. Add or modify the following configuration to stop automatic suggestions and inline ghost text: 
    {
  "editor.quickSuggestions": {
    "other": false,
    "comments": false,
    "strings": false
  },
  "editor.inlineSuggest.enabled": false,
  "editor.suggestOnTriggerCharacters": false,
  "editor.acceptSuggestionOnEnter": false,
  "editor.autoClosingBrackets": false
}

03. Why Python?

Python is consistently ranked as the world's most popular programming language on the TIOBE Index. Its clean, human-readable syntax makes it the standard choice across data science, web development, automation, and AI development.

Furethermore, while the AP Exam is language agnostic, Python mimics the format of the AP Exam code blocks quite well.

04. Activity A: File Management

An important part of this class will be file management. Therefore, let's set this up now:

Pick where your files for this class will live: on your desktop, or in your documents. Avoid locations like your downloads or somewhere deep inside your program files.

If you're using PyCharm, we will create a new project in the program and it will setup our first folder for us:

  1. Click New Project.
  2. Give the project the name CSP.
  3. For the Location, choose your desktop or your documents (no new folder yet).
  4. You can leave everything else default, except, ensure that Create a welcome script is unchecked.
  5. Click Create. PyCharm will create the new CSP folder for you (along with some other files and folders PyCharm needs to run).

If you're using VS Code, we will set up the folder first:

  1. Create a new folder in your Documents or on your Desktop and call it CSP.
  2. Everything you create for this class will live in this folder.

05. Activity B: The Zen of Python

After your software finishes installing, test your installation and uncover Python's core design philosophy hidden inside the language itself.

  1. Open your IDE.
  2. Create a new file named zen.py.
  3. Type the following line of code:
zen.py python 
import this
zen.py
Python 
import this

Run the script by clicking the Play button (▶) in the top-right corner of your IDE. The terminal will print The Zen of Python by Tim Peters—a set of 19 guiding principles for writing clean code.

Keyboard shortcuts will help immensely with your productivity in this class. The first one I recommend right from the start is Ctrl/Cmd + S - Save your work. This is pretty universal with any program.

06. Activity C: Hello, World!

It is a rite of passage for every programmer across the globe to write a "Hello, World!" program when learning a new language.

  1. Create a new folder inside of your main CSP folder (this will be referred to as the root folder of our class) called learning.
  2. Create a new file named hello-world.py in the learning folder.
  3. Enter the following code and run your program:
hello-world.py
Python 
print("Obligatory, Hello World!")
