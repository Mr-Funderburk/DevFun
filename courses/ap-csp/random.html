Randomness & Computer Simulations

Learn how to import Python's random module to generate pseudo-random numbers, make random selections from collections, and model real-world events.

1. Introduction to Pseudo-Randomness

Computers are inherently deterministic machines—given the exact same input and sequence of instructions, they will always produce the exact same output. So how can a computer generate a "random" number?

Python uses a Pseudo-Random Number Generator (PRNG). PRNGs use mathematical algorithms starting from an initial value (called a seed) to produce sequences of numbers that appear completely random for practical purposes.

To use randomness in Python, you must first import the standard random module at the very top of your program:

import_example.py
Python 
import random

# All random functions are accessed using dot notation:
# random.randint(), random.choice(), etc.

2. Generating Random Numbers

Depending on your application (e.g., rolling dice vs. generating continuous probability floats), Python provides three primary numeric functions:

Loop Comparison Table
Function Data Type Description & Range Example
random.randint(a, b) Integer Returns a random integer in range [a, b] (inclusive on both ends). random.randint(1, 6) → 1, 2, 3, 4, 5, or 6
random.random() Float Returns a floating-point number in range [0.0, 1.0]. random.random() → 0.734102...
random.uniform(a, b) Float Returns a random float in range [a, b]. random.uniform(5.0, 10.0) → 7.4281...
numeric_random.py
Python 
import random

# Simulate rolling a standard 6-sided die
die_roll = random.randint(1, 6)
print(f"You rolled a {die_roll}")

# Probability check (30% chance of critical hit)
crit_chance = random.random()
if crit_chance < 0.30:
    print("CRITICAL HIT!")
else:
    print("Normal attack.")

# Generate temperature readout between 97.0 and 103.0 Fahrenheit
temp = random.uniform(97.0, 103.0)
print(f"Patient temperature: {temp}°F")

3. Random Choices from Collections

When working with lists, tuples, or strings, you often need to select items at random or rearrange their order.

A. Selecting a Single Element: random.choice()

Passes a collection to random.choice() and returns one random item. Throws an IndexError if the collection is empty.

B. Selecting Multiple Elements: Replacement vs. Unique

  • random.choices(population, k=N) (With Replacement): Picks N items. The same item can be picked multiple times (like rolling a die multiple times).
  • random.sample(population, k=N) (Without Replacement): Picks N unique items. No item is repeated (like drawing cards from a deck).

C. Shuffling in Place: random.shuffle()

Randomly reorders the elements of a mutable list directly in memory. Returns None.

collection_random.py
Python 
import random

students = ["Alice", "Bob", "Charlie", "Diana", "Ethan", "Fiona"]

# 1. Pick 1 student to present first
presenter = random.choice(students)
print(f"First presenter: {presenter}")

# 2. Pick 3 distinct team leaders (No duplicates!)
leaders = random.sample(students, k=3)
print(f"Team Leaders: {leaders}")

# 3. Simulate 5 coin flips (Duplicates allowed!)
coin_sides = ["Heads", "Tails"]
flips = random.choices(coin_sides, k=5)
print(f"Coin Flips: {flips}")

# 4. Shuffle a deck / list in place
deck = ["Ace", "King", "Queen", "Jack", "10"]
random.shuffle(deck)
print(f"Shuffled Deck: {deck}")

4. Advanced Topic: Reproducibility with random.seed()

Because PRNG algorithms calculate the next random number based on the previous state, setting the starting point—the seed—produces identical results every time the program runs. This is essential for:

  • Debugging: Testing code against predictable "random" data.
  • Procedural Generation: Creating identical video game worlds using a world seed (e.g., Minecraft, No Man's Sky).
  • Scientific Research: Ensuring experiments can be replicated by other researchers.
seed_demo.py
Python 
import random

# Setting seed to 42
random.seed(42)
print(random.randint(1, 100))  # Always outputs 82
print(random.randint(1, 100))  # Always outputs 15

# Re-setting the exact same seed resets the sequence
random.seed(42)
print(random.randint(1, 100))  # Outputs 82 again!

Quick Tip: Formatting Decimals in F-Strings

When working with functions like random.uniform() or calculating percentages in simulations, Python often returns floating-point numbers with many decimal places (e.g., 98.643182049...). You can clean up your output using f-string format specifiers.

By adding a colon (:) followed by .nf inside an f-string expression, you tell Python to round the display output to n decimal places without altering the underlying numeric value:

String Formatting Table
Format Specifier Meaning Example Value Formatted Output
{val:.1f} Round float to 1 decimal place 98.6432 "98.6"
{val:.2f} Round float to 2 decimal places 16.6666 "16.67"
{val:.0f} Round to 0 decimal places (nearest whole number) 7.89 "8"
{val:,.2f} Add thousand separators (commas) + 2 decimal places 1250000.5 "1,250,000.50"
{val:.1%} Convert float ratio to percentage + 1 decimal place 0.1667 "16.7%"
formatting_examples.py
Python 
import random

# Generate a float with many decimal places
temp = random.uniform(97.0, 103.0)  # e.g., 98.643182049
win_rate = 1 / 6                    # 0.16666666666666666

# Clean display formatting:
print(f"Patient temperature: {temp:.1f}°F")   # Output: Patient temperature: 98.6°F
print(f"Probability: {win_rate:.2f}")         # Output: Probability: 0.17
print(f"Win Rate: {win_rate:.1%}")            # Output: Win Rate: 16.7%

# Combining commas and decimal places for large numbers
score = 1250000.75
print(f"High Score: {score:,.2f} pts")        # Output: High Score: 1,250,000.75 pts

5. Computer Simulations (AP CSP Big Idea)

In Computer Science, simulations use mathematical models and pseudo-random numbers to emulate real-world systems. Simulations allow scientists to test hypotheses without the expense, time, or danger of physical experiments.

The program below models rolling two 6-sided dice 10,000 times to calculate the empirical probability of rolling a sum of 7:

dice_simulation.py
Python 
import random

SIMULATION_RUNS = 10000
sevens_count = 0

for _ in range(SIMULATION_RUNS):
    die1 = random.randint(1, 6)
    die2 = random.randint(1, 6)
    
    if die1 + die2 == 7:
        sevens_count += 1

percentage = (sevens_count / SIMULATION_RUNS) * 100
print(f"Total Sevens Rolled: {sevens_count} / {SIMULATION_RUNS}")
print(f"Experimental Probability: {percentage:.2f}% (Theoretical: 16.67%)")

Common Pitfalls Summary

  • Assigning random.shuffle() to a variable: my_list = random.shuffle(my_list) sets my_list to None! Call random.shuffle(my_list) on its own line.
  • Sampling more items than exist: Calling random.sample(my_list, k=10) on a list with only 5 items raises a ValueError. Use random.choices() if replacement is allowed.
  • Forgetting import random: Always verify your import statement is present at line 1.
