Layout Replication Challenge

The Ultimate Design Blueprint Challenge

In client-world web development, you are rarely asked to invent layouts from scratch. Instead, designers hand you a visual mock-up or spec sheet, and your job as a front-end developer is to translate that picture into clean, pixel-perfect HTML and CSS.

In this challenge, your instructor will project or provide a screenshot of a target layout. Your task is to inspect the visual details and write the complete HTML and CSS code required to replicate the layout precisely!

No Source Code Provided!

You will only receive the visual image of the final website. You must determine which semantic HTML tags to write, which CSS layout system (Flexbox vs. CSS Grid) fits each section, and how to position floating badges and hover effects.

Deconstructing the Challenge Layout

Analyze the screenshot provided by your instructor carefully. The target layout contains five major layout structural features:

  1. Sticky Header & Flex Navigation: A top navigation bar pinned to the top of the viewport containing a brand logo, navigation links, and a primary CTA button aligned with Flexbox.
  2. Asymmetrical Bento Hero Grid: A 2-column or 3-column hero section built using CSS Grid. The main featured card spans across 2 rows and contains a floating badge anchored in the top-right corner using absolute positioning.
  3. 3-Card Feature Grid: A lower section containing three equal-width feature cards that wrap smoothly using Flexbox or Grid.
  4. Sidebar & Main Content Split: The primary page content is split into a 2-column layout with a wider main content zone (2.5fr) and a narrower sidebar (1fr).
  5. Interactive Hover Micro-Interactions: Moving the mouse over cards or navigation buttons smoothly shifts background fills, borders, or slightly elevates cards using transitions.

Technical Requirements Checklist

Your code submission must strictly meet all of the following technical constraints:

Technical Evaluation Criteria
Requirement Category Technical Expectation
File Architecture A root folder named layout-challenge-1/ containing index.html, style.css, and an css/ subfolder.
HTML Semantics Must use valid semantic HTML5 markup: <header>, <nav>, <main>, <article>, <aside>, and <footer>. Limit generic <div> spaghetti!
CSS Layout Engines Must utilize CSS Grid for the 2D bento grid & main page split, and Flexbox for header link distribution and card alignments.
CSS Positioning Must implement correct positioning (sticky, relative, absolute)
Interactive States Must feature :hover state transitions on buttons, links, and cards.

Recommended Strategy for Success

  1. Draw the Boxes First: Look at the screenshot and draw bounding boxes around the major sections. Identify which element is the parent container and which are the children.
  2. Build HTML Skeleton First: Write all your semantic HTML structure before touching CSS. Make sure all parent and child tags are properly nested and indented!
  3. Add Universal Reset: Start your CSS file with * { margin: 0; padding: 0; box-sizing: border-box; } to eliminate browser default offset quirks.
  4. Work Top-to-Bottom: Style the sticky header first, then move to the hero grid, main content layout, sidebar, and finally the footer.
