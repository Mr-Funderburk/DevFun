Lesson 001: Demystifying the Web

Topic HTML5 Fundamentals & Web Mechanics
Core Concept Web pages are plain text documents parsed by browsers

01. How the Web Works

Websites are not mysterious compiled programs. They are simply plain text files containing code instructions that your web browser (Chrome, Firefox, Safari) reads and renders visually on screen.

>_ Developer Secret: Inspect Element

You can peek under the hood of any site on the internet. Right-click anywhere on a webpage, select Inspect, and you will open DevTools. You can temporarily edit text or HTML live in your browser to test ideas without changing the actual website!

02. File System & Workspace Rules

Before writing code, configure your project workspace correctly. Broken images and missing pages in web development are almost always caused by improper file naming or folder paths.

! The Golden Rules of Web File Management
  • Use Lowercase: Always write folder and file names in lowercase (e.g., index.html).
  • No Spaces: Never use spaces in file names. Use hyphens instead (e.g., my-first-page.html).
  • Standard Entry Point: The main homepage of any web project folder must be named index.html.
  • Keep It Organized: Store all project files inside a dedicated course folder structure:
    web-dev-1 / lesson-01 / index.html

03. The HTML5 Boilerplate

Every HTML page requires a standard set of setup tags called a boilerplate. This tells the browser which HTML standard you are using and defines where invisible metadata ends and visible content begins.

index.html
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Web Page</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>I am building a website from scratch!</p>
</body>
</html>
Element Function
<!DOCTYPE html> Informs the browser that this document uses modern HTML5.
<html> The root container wrapping all elements on the page.
<head> Holds invisible page data (tab title, styles, metadata).
<body> Holds all visible content displayed inside the main browser window.

04. HTML Tags & Text Reference

HTML elements use tags to label content. Most elements use matching opening and closing tags acting like bookends around content.

Anatomy of a Tag

<p>This is paragraph content.</p>
 ^ Opening Tag                 ^ Closing Tag (Notice the forward slash)

Headings (Hierarchy)

Headings establish visual structure and help search engines understand your content structure. Use <h1> for the primary title, down to <h6> for sub-topics.

headings.html
HTML 
<h1>Main Page Title</h1> <!-- Rule: Use only ONE <h1> per page! -->
<h2>Section Title</h2>
<h3>Sub-section Heading</h3>

Paragraphs & Inline Formatting

Use <p> tags for main text blocks. To emphasize specific words inside a paragraph, wrap them in inline tags like <strong> or <em>.

formatting.html
HTML 
<p>I am <strong>bolding important words</strong> and <em>italicizing phrases</em>.</p>
<hr> <!-- <hr> creates a horizontal line divider (Self-closing: no closing tag needed) -->

05. Try It Yourself: Challenges

Challenge 1: Personal Mini-Bio

Open your index.html file in VS Code and expand your page using the concepts covered above:

  • Add an <h2> subtitle below your main heading (e.g., About Me or My Favorite Technologies).
  • Write a two-sentence paragraph describing a project or game you want to build.
  • Use <strong> to bold key terms and <em> to italicize a title.
  • Add an <hr> divider line between sections.

Challenge 2: Debugging Experiments

Web browsers don't display giant red error screens when HTML breaks—they make an educated guess about what you meant. Test these intentional bugs to see how browsers behave:

  • Missing End Tag: Delete a closing tag (e.g., </h1>). Save, refresh your browser, and notice how downstream text inherits the heading style.
  • Typo in Tag Name: Rename a tag to an invalid term (e.g., <headder>). Observe how the browser treats unknown tags as unstyled plain inline text.
  • Improper Nesting: Swap closing tags incorrectly (e.g., <p><em>Text</p></em>). Notice how browser DevTools attempts to fix the tree automatically.
★ Workflow Checklist
  • Proper Nesting: Close elements in reverse order of opening (e.g., <p><strong>Text</strong></p>).
  • Save & Refresh: Save edits in your code editor (Ctrl+S / Cmd+S), then reload the page in your browser (F5 / Cmd+R).
