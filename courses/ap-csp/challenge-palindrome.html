Weekly Challenge: Deep Space Telemetry — Symmetric Echo Validator

Parse laser telemetry streams, eliminate spacing artifacts, and verify bi-directional mirror symmetry in planetary signals.

Introduction

Deep-space exploration probes transmit laser telemetry signals back to Earth across millions of miles. To verify that laser communication pulses are not distorted by solar radiation or space dust, receiving stations employ a Symmetric Mirror Echo Protocol.

A sequence is considered a valid palindrome if it reads identically forward and backward (e.g., "Madam", "123321", or "$a3*3A$"). Space interference often introduces random spaces or capitalization shifts into the optical link; therefore, your validator must normalize signals before checking for symmetry.

Your task is to build an automated Symmetric Echo Validator. Your software must accept a sequence argument, strip out space padding, ignore case differences, evaluate bi-directional symmetry, and return a boolean status.

Program Requirements

Strict Naming & Coding Specifications:

  • File Naming Rule: Name your Python file palindrome_lastname.py where lastname is replaced by your official last name (e.g., palindrome_funderburk.py).
  • Student Identifier Constant: Define a global variable near the top of your script:
    NAME = "Your First and Last Name"
  • Function Signature: Define a function named palindrome(msg) that accepts one parameter: msg (a string containing letters, numbers, or symbols).
  • Return Output Requirement: Your function must return a boolean value:
    • True
    • False

Sample Test Cases

Test Cases Table
Input Sequence (msg) Expected Return Value Validation Reasoning
"Madam" True Reads as "madam" forward and backward.
"AbBa" True Normalized: "abba". Symmetric match.
"123321" True Numeric sequence reads identically reversed.
"$a3*3A$" True Normalized: "$a3*3a$". Symbols and numbers are symmetric.
"Kangaroo" False "kangaroo" ≠ "ooragnak".
"$!(OK)!$" False Symbols match, but inner "ok" ≠ "ko".
"abAB" False Normalized: "abab" ≠ "baba".

Test Your Code Locally

Copy and paste the test harness below into the bottom of your Python file to run automated checks against the sample inputs:

challenge-palindrome.py
Python 
if __name__ == "__main__":
    sample_tests = [
        ("Madam", True),
        ("AbBa", True),
        ("123321", True),
        ("$a3*3A$", True),
        ("Kangaroo", False),
        ("$!(OK)!$", False),
        ("abAB", False)
    ]

    print("\n--- RUNNING LOCAL TESTS ---")
    passed = 0
    for sample_input, expected in sample_tests:
        actual = palindrome(sample_input)
        if actual == expected:
            print(f"PASS: '{sample_input}'")
            passed += 1
        else:
            print(f"FAIL: '{sample_input}'\n   Expected: {expected}\n   Got:      {actual}\n")
            
    print(f"Result: {passed}/{len(sample_tests)} sample tests passed.\n")
