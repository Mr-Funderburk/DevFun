CSS Grid Layout

The Power of Two-Dimensional Layouts

In previous lessons, we mastered Flexbox, which is designed for one-dimensional layouts (aligning items along a single row OR a single column). But what happens when you need to align items horizontally AND vertically at the same time—like a magazine layout, photo wall, or app dashboard?

Welcome to CSS Grid Layout. CSS Grid is a true two-dimensional layout engine that lets you construct complex rows and columns simultaneously with incredible precision.

Flexbox vs. CSS Grid Comparison
Layout System Dimension Design Approach Best Used For...
Flexbox 1D (Rows or Columns) Content-First (Items flow naturally) Navbars, button groups, stacked card lists, alignment within cards.
CSS Grid 2D (Rows and Columns) Layout-First (Structure defined upfront) Full page frameworks, photo walls, dashboards, magazine bento grids.

1. Setting Up the Grid Container

Just like Flexbox, CSS Grid operates on a parent-child relationship. Turning a parent element into a Grid Container automatically turns all direct child elements into Grid Items.

grid-setup.css
CSS 
.grid-container {
    display: grid;
    grid-template-columns: 200px 200px 200px; /* Defines 3 columns, each 200px wide */
    grid-template-rows: 150px 150px;         /* Defines 2 rows, each 150px tall */
    gap: 20px;                               /* 20px spacing between all cells */
}

2. Sizing Units: The Fractional Unit (fr)

Hardcoding pixel values like 200px creates rigid layouts that break on small screens. CSS Grid introduces a powerful flexible unit: the Fractional Unit (fr).

One fr represents one fraction of the available free space inside the grid container:

  • grid-template-columns: 1fr 1fr 1fr; — 3 equal columns, each taking 1/3 of the container width.
  • grid-template-columns: 1fr 2fr; — 2 columns: column two is twice as wide as column one.
  • grid-template-columns: 250px 1fr; — Fixed 250px sidebar, while the second column stretches to fill all remaining space!

3. Grid Shorthands: repeat() & minmax()

Writing out 1fr 1fr 1fr 1fr gets tedious. CSS gives us helper functions to write cleaner code:

The repeat() Function

Repeats a track sizing pattern a specified number of times:

grid-template-columns: repeat(4, 1fr); /* Creates 4 equal columns */

The Responsive Magic: auto-fit + minmax()

Want a fully responsive grid that automatically adjusts the number of columns based on screen width—without writing a single media query? Combine auto-fit with minmax()!

responsive-grid.css
CSS 
.responsive-gallery {
    display: grid;
    /* Fit as many columns as possible, but never let a column shrink below 250px! */
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

How `auto-fit` + `minmax()` Works

On a large desktop screen, the container fits four 250px columns side-by-side. As you shrink the browser window, columns automatically drop off and wrap onto new rows, while remaining cards expand to fill the empty space smoothly!

4. Spanning Items Across Columns & Rows

Grid items don't have to sit inside a single cell! You can tell a grid item to stretch across multiple columns or rows using grid-column and grid-row.

item-spanning.css
CSS 
/* Span an item across 2 column tracks */
.feature-card {
    grid-column: span 2;
}

/* Span an item across 2 row tracks */
.tall-card {
    grid-row: span 2;
}

/* Explicit line positioning: Start at line 1, end at line 3 */
.header-card {
    grid-column: 1 / 3;
}

Putting It Together: The Bento Dashboard Grid

In your web-1/learning/ folder, create a new file named grid-dashboard.html and link it to grid-dashboard.css.

grid-dashboard.html
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Bento Grid Dashboard</title>
    <link rel="stylesheet" href="css/grid-dashboard.css">
</head>
<body>
    <main class="dashboard-wrapper">
        <header class="header">
            <h1>Interactive Bento Grid</h1>
            <p>Combining 2D Grid layouts with item column/row spanning.</p>
        </header>

        <div class="bento-grid">

Now write the accompanying CSS Grid layout in grid-dashboard.css:

grid-dashboard.css
CSS 
/* Universal Reset */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    background-color: #0b1020;
    color: #e2e8f0;
    font-family: sans-serif;
    padding: 32px 16px;
}

.dashboard-wrapper {
    max-width: 1000px;
    margin: 0 auto;
}

.header {
    text-align: center;
    margin-bottom: 32px;
}

.header h1 {
    color: #38bdf8;
    margin-bottom: 8px;
}

.header p {
    color: #94a3b8;
}

/* 1. Mobile-First Grid Setup (1 Column by default) */
.bento-grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 20px;
}

/* Standard Bento Cards */
.card {
    background-color: #151d32;
    border: 2px solid #334155;
    border-radius: 12px;
    padding: 24px;
    transition: border-color 0.2s ease, transform 0.2s ease;
}

.card:hover {
    border-color: #38bdf8;
    transform: translateY(-2px);
}

.card h3 {
    color: #f8fafc;
    margin-bottom: 6px;
}

.card p {
    color: #94a3b8;
    font-size: 0.95rem;
}

.tag {
    display: inline-block;
    background-color: #0f2b48;
    color: #38bdf8;
    font-size: 12px;
    font-weight: bold;
    padding: 4px 10px;
    border-radius: 6px;
    margin-bottom: 12px;
}

/* 2. Desktop Grid Breakpoint (3 Columns + Custom Item Spanning) */
@media (min-width: 768px) {
    .bento-grid {
        /* Explicit 3-column 2D grid structure */
        grid-template-columns: repeat(3, 1fr);
    }

    /* Wide card spans across 2 columns */
    .card-wide {
        grid-column: span 2;
        background-color: #1b2845;
        border-color: #38bdf8;
    }

    /* Tall card spans down across 2 rows */
    .card-tall {
        grid-row: span 2;
        background-color: #1a233a;
    }
}

Practice Exercise & Challenges

Put CSS Grid concepts into action with these hands-on layout challenges:

  1. Build a 12-Column Layout System: Set up a container with grid-template-columns: repeat(12, 1fr);. Create a main content box that spans 8 columns (grid-column: span 8;) and a sidebar that spans 4 columns (grid-column: span 4;).
  2. Construct a Photo Wall Gallery: Create a gallery with 6 images using repeat(auto-fit, minmax(200px, 1fr)). Pick two images and make them span across 2 columns to give the gallery a dynamic magazine look!
  3. DevTools Grid Inspection: Open Google Chrome DevTools (F12), click on the .bento-grid container in the Elements panel, and toggle the Grid overlay button. Inspect the numbered grid line numbers on your screen!
