Project: Bio Link Page

Project Overview

It's time to put your HTML and CSS skills into practice! In this project, you will build a personalized single-page "Bio Link" page showcasing 5 key things that make up your life—such as hobbies, favorite places, family, games, or passions.

This assignment directly tests your understanding of semantic HTML markup and the CSS Box Model (padding, borders, margins, and sizing). Your page will act as a digital hub containing photos, descriptions, and outgoing web links for each topic.

Example Topic Ideas

Unsure what topics to pick? Here are five real-world examples:

  • Family & Friends — A section about your household or pet.
  • Gaming (e.g., Path of Exile) — A section about your favorite video game.
  • Culinary / Food — A section highlighting favorite dishes or cooking experiences.
  • Swimming & SCUBA — A section sharing your outdoor or athletic activities.
  • Coding & Web Development — A section reflecting on your journey building websites!

Core Requirements Checklist

Ensure your project submission fulfills every item listed below:

  1. Header Section: A page header containing a main title (e.g., "My Bio Links" or "Things That Define Me") alongside your full name.
  2. At Least 5 Life Topics: Create 5 distinct content cards/sections. Each topic must contain all four of the following elements:
    • Heading: An <h2> tag naming the activity or subject.
    • Paragraph: An explanatory <p> describing why this topic is meaningful to you.
    • Relative Image Link: A local image file loaded from your project folder using a relative path (e.g., src="img/path-of-exile.jpg").
    • Absolute External Link: An outgoing hyperlink opening an official external website related to the topic (e.g., href="https://www.pathofexile.com").
  3. Semantic HTML5 Markup: Use semantic structural tags such as <header>, <main>, <section>, <article>, and <footer>. Avoid wrapping your entire page in generic <div> tags!
  4. External Stylesheet: All styles must be written in an external stylesheet (e.g., bio-links.css) linked inside your HTML <head> tag. Inline style attributes are not permitted.

Grading Focus: The CSS Box Model

Because this project focuses heavily on spacing mechanics, grading will center on your mastery of the CSS Box Model. A page with squished text or overlapping borders will lose points—use Box Model rules deliberately to refine your layout:

Box Model Problem & Solution Guide
Layout Problem Diagnosis CSS Box Model Solution
Text squished directly against card edges Missing inner space Add padding inside the card container.
Cards jammed tightly against each other Missing outer space Add margin-bottom or flex gap to separate sections.
Images overflowing past section borders Unrestricted element sizing Set max-width: 100%; height: auto; on images.
Card width bursting unexpectedly when padding is added Default box model sizing Apply universal box-sizing: border-box; reset rule!

Project Point Breakdown Rubric

Your submission will be evaluated according to four main criteria:

Grading Rubric
Criteria Expectation Points
Box Model Application Proper use of padding inside containers, clear margins separating elements, and controlled image widths. No text touching borders. 35 pts
Required Content & Links 5 complete topics with headings, paragraphs, relatively linked images (img/), and absolute links (https://). 30 pts
HTML Semantics & Structure Valid semantic tags (<header>, <main>, <article>, <footer>) without broken tags or unclosed attributes. 20 pts
External CSS & Visual Design All styles defined in external .css file. Clean color choices, visible hover states, and clear typography hierarchy. 15 pts

Step-by-Step Submission Instructions

  1. Create Project Folder: In your local directory, create a folder named projects/bio-link/.
  2. Image Folder Setup: Create an img/ subfolder inside your project directory. Download 5 topic images and place them inside.
  3. Build HTML & CSS: Create index.html and style.css. Link your stylesheet and construct your 5 sections using relative image paths and absolute external web links.
  4. DevTools Box Model Check: Right-click your elements in the browser and choose Inspect. Hover over elements in the DevTools Elements panel to check padding (green highlight) and margin (orange highlight)!
  5. Verify Links: Click all 5 external links to ensure they open the intended website, and verify that all local images render without broken image icons.
