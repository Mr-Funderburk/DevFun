Octal & Base-8 Conversions

Explore the Base-8 number system, master 3-bit binary chunking shortcuts, and learn how octal powers Unix system file permissions.

AP CSP Exam Alignment Note

Like Hexadecimal, Octal is not tested on the AP Computer Science Principles exam. However, base-8 provides an ideal bridge for understanding how positional number systems work and is heavily used in operating systems for configuring security permissions.

1. What is Octal? (Base-8)

Octal is a Base-8 positional number system that uses eight distinct symbols: 0, 1, 2, 3, 4, 5, 6, and 7.

Unlike Hexadecimal (Base-16), Octal does not require letter characters (A-F). Because the maximum single-column digit in Base-8 is 7, every octal position fits comfortably within standard single-digit decimal numbers!

2. Standard Base-8 Mathematical Conversions

Octal positional values increase right-to-left as powers of eight (80 = 1, 81 = 8, 82 = 64, 83 = 512).

Converting Octal to Decimal (Base-8 → Base-10)

Multiply each octal digit by its positional power of 8 and sum the totals.

Example: Convert Octal 3578 to Decimal:

(3 × 82) + (5 × 81) + (7 × 80) = (3 × 64) + (5 × 8) + (7 × 1) = 192 + 40 + 7 = 23910

Converting Decimal to Octal (Base-10 → Base-8)

Repeatedly divide the decimal number by 8. Record the remainder for each step and write the remainders from bottom to top.

Example: Convert Decimal 20510 to Octal:

  1. 205 ÷ 8 = 25 with a remainder of 5 (Least Significant Digit - rightmost).
  2. 25 ÷ 8 = 3 with a remainder of 1.
  3. 3 ÷ 8 = 0 with a remainder of 3 (Most Significant Digit - leftmost).
Reading remainders bottom-to-top yields: 3158

3. The Human Shortcut: The 3-Bit Binary Bridge

Because 8 = 23, exactly one octal digit corresponds to three binary bits. Instead of performing long division by 8, you can use 3-bit binary chunks to convert quickly on paper!

The 3-Bit Binary Bridge Rule

Hexadecimal uses 4-bit nibbles (24 = 16). Octal uses 3-bit chunks (23 = 8).

Shortcut 1: Octal → Binary → Decimal

Convert Octal 3158 to Decimal using the Binary Bridge:

  1. Split Octal 315 into individual digits: 3, 1, and 5.
  2. Convert each digit into a 3-bit binary chunk using [4, 2, 1] weighting:
    • 3 (2 + 1) = 011
    • 1 (1) = 001
    • 5 (4 + 1) = 101
  3. Combine the 3-bit chunks: 011 001 1012 (or 110011012).
  4. Convert the 8-bit binary string to decimal:
    128 + 64 + 8 + 4 + 1 = 20510.

Shortcut 2: Decimal → Binary → Octal

Convert Decimal 18010 to Octal using the Binary Bridge:

  1. Convert Decimal 180 to binary: 1011 01002.
  2. Group the binary bits into chunks of 3 starting from the right (add leading zeros on the left if necessary):
    010 | 110 | 100
  3. Convert each 3-bit chunk independently using [4, 2, 1] weighting:
    • 010 = 2 → 2
    • 110 = 4 + 2 = 6 → 6
    • 100 = 4 → 4
  4. Combine the digits: 2648.

4. Real-World Application: Unix File Permissions

The most famous application of octal numbers in modern software development is configuring file security permissions on Linux and macOS operating systems (via the chmod command).

Every file in Unix has three security permission groups: User (Owner), Group, and Others. Each group is assigned three binary flag bits: Read (r), Write (w), and Execute (x).

Permission Flag Binary Weight Bit Active Value
Read (r)22 = 41002 = 4
Write (w)21 = 20102 = 2
Execute (x)20 = 10012 = 1

Because each permission category is exactly 3 bits, it maps perfectly to a single Octal Digit (0 through 7)!

Example: chmod 755 script.sh

  • User (Owner) = 7 (rwx): 4 + 2 + 1 = 7 → Read, Write, and Execute permitted.
  • Group = 5 (r-x): 4 + 0 + 1 = 5 → Read and Execute permitted (No Write).
  • Others = 5 (r-x): 4 + 0 + 1 = 5 → Read and Execute permitted (No Write).

5. Octal Notation in Python (`0o`)

In Python, octal integer literals are designated using a 0o (zero + lowercase 'o') prefix:

octal_notation.py
Python 
# Python automatically evaluates 0o octal prefix to integer decimal values
oct_val = 0o357
print(oct_val)  # Prints: 239

# Convert decimal to octal string in Python:
print(oct(205))  # Output: '0o315'

# Verify 3-bit binary representation:
print(bin(0o755))  # Output: '0b111101101'
