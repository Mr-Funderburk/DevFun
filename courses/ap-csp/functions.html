Functions in Python

Introduction to Modular Code

Up to this point, our code segments run linearly from top to bottom and execute exactly once. But what if you need to run the same sequence of instructions five, ten, or a hundred times throughout a program? Rewriting or copy-pasting the same code over and over makes programs messy, difficult to maintain, and prone to bugs.

To follow the software design principle known as DRY (Don't Repeat Yourself), we package reusable code blocks into functions. A function is a named block of instructions designed to perform a specific task. Once defined, a function can be invoked (called) whenever and wherever it is needed.

Defining and Calling a Function

Every Python function begins with the keyword def (short for define), followed by the function name, parentheses (), and a colon :. The lines inside the function form its body and must be indented.

functions.py
Python 
# Defining the function
def canterbury_honor_code():
    print("I will act honorably respecting myself and others. I will not lie, cheat, steal, or plagiarize.")

# Calling (executing) the function
canterbury_honor_code()
canterbury_honor_code() # Can be called as many times as needed!

Naming Conventions & Function Headers:

The function name and its parameter list together are called the function header (or function signature). Function names follow the exact same naming rules as variables: use only letters, numbers, and underscores, do not start with a number, avoid reserved keywords, and stick to snake_case in Python.

Parameters vs. Arguments

Functions become much more powerful when they can accept dynamic inputs. We pass data into functions using parameters and arguments:

  • Parameters: Variables defined inside the function header that act as placeholders for incoming data.
  • Arguments: The actual values or variables passed into the function when you call it.
functions.py
Python 
# 'num1' and 'num2' are PARAMETERS
def calc_two_nums(num1, num2):
    if num1 == num2:
        return "Doubled Sum: " + str(2 * (num1 + num2))
    else:
        return "Sum: " + str(num1 + num2)

# '10' and '20' are ARGUMENTS passed into the function
result_one = calc_two_nums(10, 20)
print(result_one)  # Outputs: Sum: 30

# Passing different arguments yields a different result
result_two = calc_two_nums(5, 5)
print(result_two)  # Outputs: Doubled Sum: 20

Return Values vs. Printing

A common point of confusion for beginner programmers is the difference between print() and return:

  • print() displays text in the console for a human to read. It does not save or pass data back to the rest of your program.
  • return sends calculated data back to where the function was called so it can be stored in a variable, passed into another function, or evaluated in a logic statement.

When a function encounters a return statement, execution of that function stops immediately. Any code written after a return inside the same execution path is unreachable and will never run.

functions.py
Python 
def add_numbers(a, b):
    return a + b
    print("This line will NEVER run because it comes after return!")

sum_val = add_numbers(3, 4) # sum_val holds 7
print(sum_val * 2)          # Outputs: 14

If a function does not contain an explicit return statement, Python automatically returns a special value called None.

Variable Scope: Local vs. Global

Where a variable is created determines where it can be accessed. This concept is known as variable scope:

  • Local Scope: Variables created inside a function (including parameters) exist only while that function is running. They cannot be read or modified outside the function.
  • Global Scope: Variables declared outside of all functions (at the main level of the file) can be read throughout the script.
functions.py
Python 
def calculate_discount(price):
    discount_rate = 0.20 # Local variable
    return price * (1 - discount_rate)

print(calculate_discount(100)) # Outputs: 80.0

# ERROR: discount_rate does not exist outside the function!
print(discount_rate) # NameError: name 'discount_rate' is not defined

The pass Keyword

In Python, empty blocks cause syntax errors because the compiler expects indented instructions after a colon. If you want to outline a function header before writing its internal logic, use the pass keyword as a temporary placeholder.

functions.py
Python 
def get_student_grade(student_id):
    # TODO: Connect to database and retrieve grade
    pass # Keeps the program runnable without syntax errors
