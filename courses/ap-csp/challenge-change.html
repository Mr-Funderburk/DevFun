Weekly Challenge: Coin Dispenser

Introduction

You are developing the software engine for a self-checkout terminal in a grocery store. However, these particular machines can only dispense coins. When a customer completes a cash transaction, the terminal's mechanical coin dispenser needs to issue change using the fewest total coins possible.

The machine holds four standard US coin denominations:

  • Quarters (25¢)
  • Dimes (10¢)
  • Nickels (5¢)
  • Pennies (1¢)

Program Requirements

File Naming Convention

Create a new Python file named change_lastname.py, replacing lastname with your actual last name in all lowercase letters.

  • Example: change_funderburk.py
  • Note: If you have multiple last names, use the first last name listed in Cougar Campus.

Constant Definition

At the top of your script (after any necessary import statements), define a fixed global variable named NAME containing your first and last name as a string:

change_lastname.py 
NAME = "Your First and Last Name"

Required Function Specification

You must write a function named change(amount) that adheres strictly to the following parameters:

  • Function Name: change
  • Parameter: amount (A string representing a currency value starting with a dollar sign, e.g., "$4.93" or "$0.42").
  • Behavior: Convert the string amount into cents and calculate the greedy distribution of quarters, dimes, nickels, and pennies needed to issue change using the fewest total coins.
  • Return Value: Returns a string containing the original formatted amount, followed by each coin count on a new line (matching the test cases below).

CRITICAL: Exact Names Required

Automated grading scripts will evaluate your submission. Your file name, function name (change), parameter name (amount), and global variable name (NAME) must match the instructions EXACTLY. Misspelling any of these elements will cause autograding scripts to fail, resulting in a lower score!
